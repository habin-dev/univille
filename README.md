# ⛰️ 캠퍼스산 (가칭)

> **필요한 걸 하러 왔다가, 같이 산을 오르게 되는 대학 커뮤니티.**
> 학교마다 캠퍼스 부지 모양의 산이 있다. 모두 산 아래에서 시작하고, 서로에게 도움이 되는 활동이 쌓일수록 안개가 걷혀 정상의 학교 대표 건물에 다가간다.

## 한 장 요약

| | |
|---|---|
| **목적** | 전국 대학생이 지금 쓰는 대학 커뮤니티 **대신** 쓰는 플랫폼 |
| **원칙** | 산은 이유가 아니라 결과. 기본 기능은 절대 잠그지 않는다 |
| **배경** | 캠퍼스 부지 모양의 3D 산. 베이스캠프 → 산길 → 중턱 → 전망대 → 정상, 위쪽은 안개 |
| **기능** | 5개 층: ① 매일 열 이유 ② 머무를 이유 ③ 사람 연결 ④ 다시 올 이유 ⑤ 나를 표현 |
| **기여** | 다른 학생에게 도움이 된 행동 (강의평, 답변 채택, 실시간 제보)이 가장 큼 |
| **보상** | 학교 전체 기여 → 안개가 걷힘. 개인 기여 → 등급·장비·편의 혜택 |
| **경쟁** | 주간 학과 등반대, 시즌 학교 대항 (누적 높이가 아니라 이번 시즌 등반량) |
| **파일럿** | **성결대학교 · 성결산**, 정상에 재림관 |
| **성공 기준** | 오픈 8주: 재학생 15% 가입, 시간표 등록 60%, D7 35%, 강의평 500개 |

## 5개 층

| 층 | 역할 | 기능 |
|---|---|---|
| 1 | 매일 열 이유 | 시간표 + 오늘 수업 카드, 강의평, 학식, 공지 요약, D-day |
| 2 | 머무를 이유 | 게시판, 질문 & 답변, **지금 캠퍼스** (실시간 제보), 학과 라운지 |
| 3 | 사람 연결 | 장터, 스터디·팀플 매칭, 같이 밥·택시, 분실물 |
| 4 | 다시 올 이유 | 기여도, 안개 해금, 등급, 학과 등반대, 학교 대항, 오늘의 등반 |
| 5 | 나를 표현 | 학과 동물 캐릭터, 등산 장비, 칭호, 정상 깃발 |
