# 🏝️ 유니빌 (UniVille) — 가칭

> **우리 학교 마을에서 놀고, 떠들고, 다른 학교를 이기자.**
> 학교마다 귀여운 마을이 하나씩 있고, 그 안에서 커뮤니티 활동을 하면 마을이 자라나며, 마을끼리 시즌제로 경쟁하는 대학생 커뮤니티 서비스.

## 한 줄 요약

기존 대학 커뮤니티는 **게시판만 있어서 재미가 없다.** 유니빌은 게시판 위에 **"우리 학교 마을"이라는 공간**과 **"학교 대항전"이라는 동기**를 더해서, 대학생이 매일 들어오고 싶은 커뮤니티를 만든다.

## 핵심 3요소

| 요소 | 설명 |
|---|---|
| 🏘️ **학교 마을** | 학교마다 2D 아이소메트릭 마을이 있음. 게시판은 마을 안의 건물(광장, 도서관, 장터, 카페…)로 존재하고, 내 아바타가 돌아다니며 다른 학생을 만남 |
| 🌳 **상징물: 학교 나무** | 마을 중앙의 큰 나무가 커뮤니티 활성도에 따라 자라고 꽃피고 열매를 맺음. 한눈에 "우리 학교가 지금 얼마나 활발한지" 보여줌 |
| 🏆 **학교 대항전** | 활성도 점수로 시즌(약 4주)마다 리그 순위를 매김. 학교 규모별 리그로 나눠 공정하게 경쟁 |
