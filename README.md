# 🏝️ 유니빌 (UniVille) — 가칭

> **우리 학교 섬에서 놀고, 떠들고, 다른 학교를 이기자.**
> 학교마다 귀여운 섬이 하나씩 있고, 그 안에서 커뮤니티 활동을 하면 섬 중심의 학교 랜드마크가 지어지고 빛나며, 섬끼리 시즌제로 경쟁하는 대학생 커뮤니티 서비스.

## 한 줄 요약

기존 대학 커뮤니티는 **게시판만 있어서 재미가 없다.** 유니빌은 게시판 위에 **"우리 학교 섬"이라는 공간**과 **"학교 대항전"이라는 동기**를 더해서, 대학생이 매일 들어오고 싶은 커뮤니티를 만든다.

## 핵심 3요소

| 요소 | 설명 |
|---|---|
| 🏝️ **학교 섬** | 학교마다 2D 아이소메트릭 섬이 있음. 게시판은 섬 안의 건물(광장, 도서관, 장터, 카페…)로 존재하고, 내 아바타가 돌아다니며 다른 학생을 만남 |
| 🏛️ **상징물: 랜드마크** | 섬 중심에 **학교 대표 건물**을 귀엽게 만든 랜드마크가 있음. 활성도에 따라 공사 중 → 완공 → 불 켜짐 → 불꽃놀이로 성장 |
| 🐾 **동물 아바타** | **학부마다 동물이 정해지고**(공대 비버, 예대 고양이…) **학교마다 색이 다름** |
| 🏆 **학교 대항전** | 활성도 점수로 시즌(약 4주)마다 리그 순위를 매김. 학교 규모별 리그로 나눠 공정하게 경쟁 |
