# 🏝️ 유니빌 (UniVille) — 가칭

> **우리 학교 섬에서 놀고, 떠들고, 다른 학교를 이기자.**
> 학교마다 귀여운 3D 섬이 하나씩 있고, 내 학과 동물 캐릭터로 섬을 돌아다니며 커뮤니티 활동을 하면 섬 중심의 학교 랜드마크가 지어지고 빛나는 대학생 커뮤니티 서비스.

## 한 장 요약

| | |
|---|---|
| **문제** | 지금 대학 커뮤니티는 게시판 목록뿐이라 재미가 없고, 필요할 때만 들어갔다 나간다 |
| **해결** | 게시판 위에 **"우리 학교 섬"**(공간)과 **"학교·학과 대항"**(동기)을 얹는다 |
| **대상** | 대학생. 첫 파일럿은 **성결대학교** |
| **핵심 루프** | 매일 출석·벽돌 → 섬 한 바퀴 → 핫글·댓글 → 주간 학과 대항 → 시즌마다 랜드마크 성장 ([11](docs/11-core-loop.md)) |
| **차별점** | 3D 섬, 학과별 동물 캐릭터, 학교 대표 건물 랜드마크, 규모 보정된 대항전 |
| **MVP** | 성결 섬 1개 + 내 캐릭터 조작 + 게시판 5개 + 랜드마크 7단계 + 학과 대항, 모바일 웹 먼저 ([12](docs/12-mvp-and-validation.md)) |
| **성공 기준** | 오픈 8주 안에 재학생 10% 가입, D7 리텐션 30% |
| **최종 목표** | 국내 대학생 대부분이 쓰는 커뮤니티 |

## 핵심 요소

| 요소 | 설명 |
|---|---|
| 🏝️ **학교 섬** | 학교마다 3D 섬. 게시판은 섬 안의 건물(광장, 도서관, 장터, 카페, 동아리 거리)이고, 내 캐릭터를 직접 움직여 들어간다. 게임이 싫으면 **리스트 모드**로 바로 게시판 |
| 🏛️ **랜드마크** | 섬 중심에 학교 대표 건물(성결대는 **재림관**). 활성도에 따라 공사 중 → 불 켜짐 → 깃발 → 불꽃놀이 → 황금까지 7단계 |
| 🐾 **동물 캐릭터** | **학과마다 동물**(공대 비버, IT 너구리, 예대 고양이…), **학교마다 옷 색** |
| 🏆 **대항전** | 학교 안에서는 주간 학과 대항, 학교끼리는 시즌 리그 (학교가 2개 이상 열린 뒤) |
