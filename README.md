# 🏫 우리캠 (가칭)

> **필요한 걸 하러 왔다가, 같이 우리 캠퍼스를 짓게 되는 대학 커뮤니티.**
> 학교마다 실제 캠퍼스 부지가 3D로 있고, 처음엔 공사 표지판뿐이다. 서로에게 도움이 되는 활동이 벽돌이 되어 우리 학교 건물이 하나씩 지어지고, 마지막에 학교 대표 건물이 완공된다.

## 한 장 요약

| | |
|---|---|
| **목적** | 전국 대학생이 지금 쓰는 대학 커뮤니티 **대신** 쓰는 플랫폼 |
| **원칙** | 캠퍼스는 이유가 아니라 결과. 기본 기능은 절대 잠그지 않는다 |
| **컨셉** | 실제 캠퍼스 부지·건물을 함께 짓는다. 첫날엔 정문 앞 **임시 천막**에서 모든 기능을 쓰고, 건물이 완공되면 기능이 건물로 이사 |
| **건물 = 기능** | 도서관 = 강의평, 강의동 = 시간표, 학생식당 = 학식, 학생회관 = 게시판… |
| **기능** | 5개 층: ① 매일 열 이유 ② 머무를 이유 ③ 사람 연결 ④ 다시 올 이유 ⑤ 나를 표현 |
| **기여** | 다른 학생에게 도움이 된 행동 = 🧱 벽돌. 행동 종류에 맞는 건물로 감 (강의평 → 도서관) |
| **보상** | 학교: 건물 완공, 랜드마크 완공 축제. 개인: 등급·장비·편의 혜택, 건물 명판 |
| **경쟁** | 주간 학과 건축팀 (학과 하우스), 시즌 학교 대항 (이번 시즌 건축량) |
| **파일럿** | **성결대학교**, 랜드마크 재림관 |
| **성공 기준** | 오픈 8주: 재학생 15% 가입, 시간표 등록 60%, D7 35%, 강의평 500개 |

## 5개 층

| 층 | 역할 | 기능 |
|---|---|---|
| 1 | 매일 열 이유 | 시간표 + 오늘 수업 카드, 강의평, 학식, 공지 요약, D-day |
| 2 | 머무를 이유 | 게시판, 질문 & 답변, **지금 캠퍼스** (실시간 제보), 학과 라운지 |
| 3 | 사람 연결 | 장터, 스터디·팀플 매칭, 같이 밥·택시, 분실물 |
| 4 | 다시 올 이유 | 벽돌, 건물 완공, 등급, 학과 건축팀, 학교 대항, 오늘의 목표 |
| 5 | 나를 표현 | 학과 동물 캐릭터, 건축 장비, 칭호, 건물 명판 |

- [`prototype/campus-3d.html`](prototype/campus-3d.html): **성결 캠퍼스 3D 프로토타입**. 내 학과 동물로 걸어 다니고, 공사 현장에서 벽돌을 쌓아 건물을 완공하면 정문 임시 천막이 건물로 이사한다. 브라우저로 열면 바로 해볼 수 있다 (인터넷 연결 필요).
- [`prototype/campus-3d-complete.html`](prototype/campus-3d-complete.html): **완공 미리보기**. 모든 건물과 재림관이 완공된 성결 캠퍼스, 완공 축제(가랜드, 불꽃놀이, 1위 학과 황금 동상).
- [`prototype/island-3d-legacy.html`](prototype/island-3d-legacy.html): **이전 섬 컨셉**의 3D 프로토타입. 캐릭터 조작, 동물 디자인, 재림관 모델, 단계별 연출은 캠퍼스 짓기에서도 참고용으로 쓴다.
