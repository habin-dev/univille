# 02. 캠퍼스 산 & 캐릭터

## 1. 산의 모양: 캠퍼스 부지

- 학교마다 **실제 캠퍼스 부지 윤곽**을 바닥 모양으로 쓰고, 그 윤곽을 안쪽으로 겹겹이 줄여 쌓아 **산 모양**을 만든다.
- 실제 지형 높이를 재현하는 것이 아니라, **"우리 학교 땅 모양의 산"**이라는 느낌을 주는 것이 목적이다.
- 부지 윤곽은 **OpenStreetMap**의 대학 부지 데이터에서 가져온다. 데이터가 없거나 부정확한 학교는 지도를 보고 직접 그린다.
  - OpenStreetMap 데이터는 ODbL 라이선스라 **출처 표기**가 필요하다.

```
 [부지 윤곽]          [안쪽으로 줄인 등고선 5겹]        [3D 산]
  ┌──────┐            ┌──────────┐                    /\
  │      └─┐          │ ┌──────┐ │                  /  \
  │        │   →      │ │ ┌──┐ │ │      →          /    \
  └────────┘          │ │ └──┘ │ │               /______\
                      │ └──────┘ │
                      └──────────┘
```

## 2. 고도 구역

등고선 한 겹이 한 구역이다. 구역마다 **열리는 공간과 기능**이 다르다.

| 구역 | 이름 | 처음 상태 | 무엇이 있나 |
|---|---|---|---|
| 0 | 🏕️ **베이스캠프** | **처음부터 열림** | 시간표, 강의평, 학식, 공지 요약, 게시판, 질문 & 답변, 지금 캠퍼스 |
| 1 | 🌲 **산길** | 안개 | 장터, 스터디·팀플 매칭, 같이 밥·택시, 분실물, 동아리 거리 |
| 2 | 🏞️ **중턱** | 안개 | 학과 라운지 꾸미기, 계절 이벤트 공간, 캠핑장(소모임 공간) |
| 3 | 🔭 **전망대** | 안개 | 다른 학교 산 구경, 전국 게시판, 학교 대항 순위판 |
| 4 | ⛰️ **정상** | 안개 | **학교 대표 건물 공개**, 정상 깃발(시즌 기록), 시즌 보상 |
| + | ❄️ **계절 봉우리** | 시즌마다 새로 생김 | 시즌 한정 공간 (눈 덮인 봉우리, 축제 광장 등) |

### ⚠️ 중요: 산길 기능도 "쓸 수는 있다"
장터, 스터디 매칭 같은 1구역 기능은 **안개가 걷히기 전에도 베이스캠프의 메뉴와 리스트 모드로 쓸 수 있다.** 안개가 걷히면 그 기능이 **산 위의 장소로 생기고 장식·이벤트가 더해질 뿐**이다.
안개 너머에만 있는 것은 "있으면 더 좋은 것"(꾸미기 공간, 다른 학교 구경, 정상 랜드마크, 시즌 보상)뿐이다. ([01 문서](01-vision.md) 원칙 2)

## 3. 안개

- 안개는 **학교 전체의 기여**로 걷힌다. 개인이 혼자 걷을 수 없다 ([04 문서](04-contribution.md)).
- 걷힌 구역은 **계속 열려 있다** (다시 안개가 끼지 않음).
- 시즌마다 정상 너머에 **계절 봉우리**가 새로 생겨서, 다 연 학교에도 다음 목표가 있다.
- 안개가 걷히는 순간은 학교 전체에 알림 + 연출 (안개가 흩어지고 새 장소가 드러남).
- 다음 구역까지 남은 양은 항상 보인다: "산길까지 72%".

## 4. 정상: 학교 대표 건물

- 정상에는 학교 대표 건물을 귀엽게 만든 **랜드마크**가 있다. 성결대는 **재림관** ([13 문서](13-pilot-sungkyul.md)).
- 처음에는 안개 속에 **실루엣만** 보인다. 정상이 열리면 건물이 드러나고, 시즌 기록이 깃발에 새겨진다.
- **실제 캠퍼스 건물은 풍경**으로 산 곳곳에 둔다. 기능은 건물이 아니라 **고도 구역**에 붙는다.
  - 이유: 실제 도서관이 산 꼭대기 쪽에 있으면, 도서관 기능이 안개에 잠겨 버리기 때문이다.

## 5. 홈 화면

3D 산은 **홈 화면 위쪽**, 바로 쓰는 카드는 **아래쪽**에 둔다.

```
┌───────────────────────────────┐
│  성결산 · 산길까지 72%  ☁️        │  ← 학교 진행도
│      (3D 산, 내 캐릭터)           │
│  📍도서관 자리 여유  🍱학식 줄 김   │  ← 지금 캠퍼스 (산 위 아이콘)
├───────────────────────────────┤
│ 다음 수업 15:00 성결관 301        │  ← 1층: 매일 쓸 이유
│ 과제 D-2 · 오늘 학식 ★4.2         │
├───────────────────────────────┤
│ 🔥 핫글 · ❓답변 기다리는 질문 3개   │  ← 2층: 머무를 이유
├───────────────────────────────┤
│ 🧗 오늘 내 기여 +12 · 학과 2위     │  ← 4층: 다시 올 이유
└───────────────────────────────┘
```

- 산을 누르면 전체 화면으로 커지고, 내 캐릭터를 직접 움직일 수 있다 (조이스틱, 키보드, 탭 이동).
- 산을 안 좋아하는 사람은 **리스트 모드**로 카드와 게시판만 쓴다. 저사양 기기는 리스트 모드가 기본값.

## 6. 캐릭터: 학과 동물

- **학과마다 동물**이 정해지고, **학교마다 옷 색**이 다르다 (학교 대표 색 후드).
- 기여 등급에 따라 **등산 장비**가 생긴다: 모자 → 배낭 → 지팡이 → 깃발 ([05 문서](05-rewards.md)).
- 무늬, 표정, 옷, 소품으로 개인 꾸미기.

### 전국 공통 계열 → 동물

학교마다 학과 이름이 다르므로 **계열**에 동물을 정하고, 학교별로 학과를 계열에 연결한다.

| 계열 | 동물 | 이미지 |
|---|---|---|
| 공학 | 🦫 비버 | 무언가를 만드는 장인 |
| IT/컴퓨터 | 🦝 너구리 | 밤샘 코딩 |
| 자연과학 | 🦉 부엉이 | 관찰과 탐구 |
| 인문 | 🐑 양 | 차분한 사색 |
| 사회과학 | 🦊 여우 | 영리함, 사회성 |
| 경영/경제 | 🐿️ 다람쥐 | 차곡차곡 모으기 |
| 사범/교육 | 🐧 펭귄 | 무리를 이끄는 선생님 |
| 체육 | 🐆 치타 | 스피드 |
| 예술/디자인 | 🐱 고양이 | 자유로운 감성 |
| 신학/종교 | 🕊️ 비둘기 | 평화 |
| 의약/간호/보건 | 🐨 코알라 | 포근한 돌봄 |
| 자유전공 | 🐰 토끼 | 어디든 갈 수 있음 (전공을 정하면 해당 동물로 진화) |

- 학과 동물은 **산 위의 내 모습**에 쓴다. 익명 글에는 기본으로 공통 아바타를 쓴다 ([07 문서](07-community-policy.md)).
- 오리지널 디자인으로 만든다. 특정 게임의 캐릭터나 그림체를 따라 하지 않는다.

## 7. 다른 학생의 존재

| 단계 | 방식 |
|---|---|
| MVP | **비동기 주민**: 최근 24시간 활동한 학생들의 캐릭터가 산을 돌아다니고, 말풍선에 최신 글·질문 제목이 뜸. 말풍선과 실제 작성자는 연결하지 않음 |
| v1 | 실시간 접속자: 지금 접속한 학생 캐릭터가 실제로 움직임, 이모지 반응 |
