# 03. 활성도 지표 & 학교 나무

## 1. 설계 원칙

1. **규모 보정**: 큰 학교가 무조건 이기면 안 된다 → **재학생 수 대비 비율**로 계산
2. **질 > 양**: 글을 많이 쓰는 것보다 **반응을 받는 좋은 글**이 더 중요
3. **넓은 참여**: 소수 헤비 유저보다 **많은 사람이 조금씩** 참여하는 게 더 높은 점수
4. **어뷰징 방지**: 도배, 매크로, 품앗이 공감으로 점수를 올릴 수 없어야 함
5. **이해하기 쉬움**: 유저는 공식이 아니라 "나무에 물 주기"로 이해

## 2. 활성도 점수 (Activity Score)

매일 학교별로 계산하고, 최근 7일 이동평균을 기본 점수로 사용한다.

```
활성도 = 100 × ( 0.35 × 참여율
               + 0.25 × 콘텐츠 점수
               + 0.20 × 상호작용 점수
               + 0.10 × 재방문율
               + 0.10 × 신규 유입 점수 )
```

| 항목 | 정의 | 왜 필요한가 |
|---|---|---|
| **참여율** (35%) | 일일 활성 유저(DAU) ÷ 인증된 재학생 수 (또는 공시 재학생 수) | 규모 보정의 핵심. 학교 크기와 무관하게 비교 가능 |
| **콘텐츠 점수** (25%) | 1인당 "유효한" 글, 댓글 수 (로그 스케일) | 글을 쓰는 문화 장려 |
| **상호작용 점수** (20%) | 글당 서로 다른 유저에게서 받은 댓글, 공감 수 | 혼자 떠드는 게 아니라 대화가 오가는지 |
| **재방문율** (10%) | 지난주 활성 유저 중 이번 주에도 들어온 비율 | 일회성 이벤트 버프 방지 |
| **신규 유입 점수** (10%) | 이번 주 신규 인증 가입자 ÷ 재학생 수 | 학교 안에서 친구를 데려오도록 유도 |

- 각 항목은 **전체 학교 분포 기준 0~1로 정규화** (예: 백분위)
- 콘텐츠 점수는 `log(1 + x)`로 계산해서 도배 효과를 줄임

### "유효한" 활동의 기준
- 글: 최소 글자 수 이상, 스팸 필터 통과, 신고로 삭제되지 않음
- 댓글/공감: **같은 유저 쌍 사이의 반복 공감은 하루 1회만 인정**
- 1인당 하루 점수 반영 상한 (예: 글 5개, 댓글 20개)
- 신고 누적, 블라인드된 글은 점수 차감

## 3. 어뷰징 방지

| 어뷰징 유형 | 대응 |
|---|---|
| 도배 | 1인당 일일 상한, 로그 스케일, 유사 문장 탐지 |
| 품앗이 공감 | 같은 유저 쌍 반복 반응 가중치 감소, 그래프 기반 이상 탐지 |
| 다중 계정 | 학교 이메일 1개당 1계정, 기기 핑거프린트 |
| 매크로 | 레이트 리밋, 행동 패턴 탐지, 의심 시 캡차 |
| 다른 학교 방해 | 다른 학교 게시판은 읽기 전용, 점수에 영향 없음 |

## 4. 상징물: 🌳 학교 나무

마을 한가운데 있는 큰 나무. **두 종류의 상태**가 있다.

### (1) 크기: 누적 성장 (시즌 동안 줄어들지 않음)
시즌 누적 활성도에 따라 단계적으로 자란다.

| 단계 | 모습 |
|---|---|
| 1 | 🌱 새싹 |
| 2 | 🌿 묘목 |
| 3 | 🌳 작은 나무 |
| 4 | 🌳 큰 나무 + 새가 날아옴 |
| 5 | 🌸 꽃이 핌 |
| 6 | 🍎 열매를 맺음 (열매 = 학교 전원에게 보상) |
| 7 | ✨ 전설의 나무 (빛나는 이펙트, 시즌 최상위권만) |

- 시즌이 끝나면 나무는 다음 시즌을 위해 리셋되지만, **나이테(역대 시즌 기록)**가 남고 지난 시즌 최고 단계에 따라 **마을 장식**이 영구 보존됨

### (2) 컨디션: 실시간 활기 (오늘의 상태)
최근 24시간 활동에 따라 바뀐다.

| 상태 | 조건 | 모습 |
|---|---|---|
| 생생함 | 평소보다 활발 | 잎이 반짝이고 나비가 날아다님 |
| 보통 | 평소 수준 | 기본 |
| 목마름 | 평소보다 조용 | 잎이 처지고 "물이 필요해요" 말풍선 |

### 개인의 기여: "물 주기"
- 유저의 유효 활동(출석, 글, 댓글, 받은 공감)이 **물방울**로 환산되어 나무에 들어감
- 나무를 터치하면 "이번 주 우리 학교 물 주기 TOP 10", "내가 준 물" 확인 가능
- 유저가 이해하는 건 공식이 아니라 **"내가 활동하면 우리 학교 나무가 자란다"**

## 5. 대안 상징물 (참고)

| 후보 | 장점 | 단점 |
|---|---|---|
| **학교 나무** ✅ | 성장 표현이 직관적, 귀여움, 계절감 | 흔한 메타포 |
| 등대/불꽃 | 밤에 빛나는 연출, 멀리서 잘 보임 | 단계 표현이 단조로움 |
| 마스코트 동물 | 캐릭터 IP로 키울 수 있음 | 학교마다 디자인 비용 |
| 마을 전체 발전 | 건물이 늘어나는 성취감 | 한눈에 비교하기 어려움 |

→ **나무를 기본으로 하고**, 학교별로 **나무 품종(벚나무, 은행나무, 소나무…)**을 고를 수 있게 해 정체성을 부여하는 것을 추천.
