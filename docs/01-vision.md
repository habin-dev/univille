# 01. 비전과 원칙

## 1. 목적

> **전국 대학생이 지금 쓰는 대학 커뮤니티 대신 쓰는 플랫폼을 만든다.**

그러려면 두 가지가 동시에 필요하다.

1. **대신 쓸 수 있을 만큼 실용적이어야 한다.** 시간표, 강의평, 게시판이 지금 쓰는 앱만큼은 돼야 한다.
2. **옮겨 올 이유가 있어야 한다.** 참여, 경쟁, 보상으로 쓰는 재미와 소속감이 생겨야 한다.

## 2. 문제

| 지금 대학 커뮤니티 | 결과 |
|---|---|
| 게시판 목록 중심이라 **볼거리, 재미가 없음** | 필요할 때만 들어갔다 나감 |
| 좋은 글, 강의평을 써도 **돌아오는 것이 없음** | 소수만 쓰고 대다수는 읽기만 함 |
| 학교 안의 활동이 **눈에 보이지 않음** | 우리 학교 커뮤니티가 살아 있는지 느낄 수 없음 |
| 학교끼리 **연결도, 비교도 없음** | 소속감과 경쟁심을 쓸 수 없음 |

## 3. 해결: 우리 캠퍼스를 함께 짓는다

학교마다 **실제 캠퍼스 부지**가 3D로 있고, 처음에는 **공사 표지판이 선 빈 터**뿐이다. 모든 기능은 정문 앞 **임시 천막**에서 바로 쓸 수 있다. 학생들이 **서로에게 도움이 되는 활동**을 하면 그 활동이 **벽돌**이 되어 관련 건물이 올라가고, 결국 **우리 학교 캠퍼스의 귀여운 미니어처**가 완성된다. 마지막 목표는 학교 대표 건물(랜드마크) 완공이다.

```
 첫날                         한 달 뒤                        한 학기 뒤
 ──────────────              ──────────────                 ──────────────
 🚧 🚧 🚧 빈 터               🏗️ 도서관 골조                 🏫 캠퍼스 거의 완성
 🚧 🚧                        🏢 학생식당 완공 ✨              🏛️ 랜드마크 마지막 공사
 ⛺⛺⛺ 정문 임시 천막          ⛺⛺ 천막 일부 이사              🎆 완공 축제
 (모든 기능 사용 가능)          (완공된 건물에 기능 입주)
```

## 4. 설계 원칙

| # | 원칙 | 의미 |
|---|---|---|
| 1 | **캠퍼스는 이유가 아니라 결과다** | 사람들은 필요한 걸 하러 온다. 그 활동이 쌓여서 캠퍼스가 지어진다 |
| 2 | **기본 기능은 절대 잠그지 않는다** | 모든 기능은 첫날부터 임시 천막과 카드로 쓸 수 있다. 건물이 완공되면 **더 좋아질 뿐**이다 |
| 3 | **기여 = 다른 학생에게 도움이 된 행동** | 강의평, 답변 채택, 정보 제보가 가장 큰 기여. 짓기 경쟁이 곧 커뮤니티 활성화가 된다 |
| 4 | **혜택은 편해지거나 예뻐지는 것만** | 다른 사람보다 위에 서는 힘(노출 우선, 투표 가중치)은 주지 않는다 |
| 5 | **3D는 선택이다** | 3D 캠퍼스가 메인이지만, 에타식 "한눈에" 2D 화면만으로도 모든 기능을 쓸 수 있다. 시작 화면은 고를 수 있다 |
| 6 | **익명은 지킨다** | 경쟁과 캐릭터가 익명을 깨면 안 된다 ([07](07-community-policy.md)) |

| 🔥 **과대 서연 (22)** | 학과 행사, 단톡 관리 | 학과 건축팀을 이끌어 학과 하우스 먼저 완공, 주간 1위 |
| 🍱 **통학생 민호 (21)** | 학식, 셔틀, 빈 강의실 정보가 아쉬움 | "지금 캠퍼스"로 실시간 정보, 제보하면 기여 |
