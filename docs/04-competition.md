# 04. 학교 대항전

## 1. 리그 구조

학교 규모 차이를 공정하게 맞추기 위해 **규모별 리그**로 나눈다.

| 리그 | 재학생 수 기준 (예시) |
|---|---|
| 🌊 대양 리그 | 2만 명 이상 |
| 🌀 바다 리그 | 1만 ~ 2만 명 |
| ⛵ 해협 리그 | 5천 ~ 1만 명 |
| 🏝️ 산호 리그 | 5천 명 미만 |

> 동물은 학부를 나타내므로 리그 이름은 바다 테마로 짓는다.

- 점수 자체는 [활성도 지표](03-activity-score.md)로 이미 규모 보정이 되어 있지만, 리그를 나누면 **"비슷한 학교끼리 겨룬다"**는 납득감이 생김
- 파일럿(성결대학교 단독) 기간에는 학교 대항 대신 **학과 대항**만 운영
- 학교가 2개 이상 되면 **단일 리그**로 시작하고, 학교 수가 20개를 넘으면 분리

## 2. 시즌

- **시즌 = 약 4주** (학기당 3~4시즌)
- 시험 기간에는 **"휴전 시즌"**: 순위 경쟁 대신 "시험 응원 미션" (공부 인증, 족보 공유 등)
- 방학에는 **"방학 리그"**: 참여 기준을 낮추고 이벤트 위주로 운영

## 3. 순위 & 보상

| 순위 | 보상 |
|---|---|
| 리그 1위 | 월드맵에서 섬에 왕관 표시, 랜드마크 황금 스킨, 전원 한정 아바타 아이템 |
| 상위 3위 | 시즌 한정 가구, 랜드마크 장식 |
| 상위 30% | 시즌 배지 |
| 학교 내 학부 1위 | 랜드마크 앞에 해당 학부 동물 동상, 학부원 전원 칭호 |
| 개인 기여 TOP 100 | 학교 명예의 전당 등록, 개인 칭호 |

- 보상은 **"학교 전원"에게 주는 것이 핵심** → "우리 학교가 이기면 나도 받는다"
- 가능하면 실물 보상(학교 앞 카페 쿠폰, 굿즈)과 제휴 → 마케팅 효과도 큼

## 4. 대항 이벤트

| 이벤트 | 내용 |
|---|---|
| ⚔️ **라이벌전** | 전통 라이벌 학교끼리 1:1 주간 대결 (지역, 체육 라이벌 등) |
| 🎉 **축제 시즌 미션** | 학교 축제 기간에 인증샷, 공연 후기 등 특별 미션 |
| 🤝 **교류전** | 두 학교가 함께 목표 달성하면 양쪽 모두 보상 (경쟁만 있으면 피로해짐) |
| 🌏 **전국 미션** | 전체 학교가 함께 목표를 채우는 서버 이벤트 |

## 5. 주의할 점

- **과열 방지**: 상대 학교 비방은 점수 차감 + 제재. 전국 광장 게시판은 모더레이션 강화
- **하위권 배려**: 꼴찌 학교에도 "성장률 1위" 같은 별도 상을 줘서 의욕을 유지
- **순위 공개 범위**: 상위권과 우리 학교 앞뒤 순위만 강조해 표시
