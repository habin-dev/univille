# 03. 기능 구성: 5개 층

> 기능을 **"매일 열 이유 → 머무를 이유 → 연결 → 다시 올 이유 → 나를 표현"** 순서로 쌓는다. 아래 층일수록 먼저 만들고, 절대 잠그지 않는다.

| 층 | 역할 | 핵심 기능 | 단계 |
|---|---|---|---|
| 1 | **매일 열 이유** | 시간표, 강의평, 학식, 공지 요약, D-day | MVP |
| 2 | **머무를 이유** | 게시판, 질문 & 답변, 학과 라운지, 지금 캠퍼스 | MVP (라운지 v1) |
| 3 | **사람 연결** | 장터, 스터디·팀플 매칭, 같이 밥·택시, 분실물 | v1 (장터는 MVP) |
| 4 | **다시 올 이유** | 기여도, 안개 해금, 학과 등반대, 학교 대항 | MVP (학교 대항 v1) |
| 5 | **나를 표현** | 동물 캐릭터, 등산 장비, 칭호, 정상 깃발 | MVP 기본형 |

---

## 1층. 매일 열 이유 (실용)

지금 쓰는 앱만큼은 돼야 하고, 한 가지라도 더 편해야 옮겨 온다.

| 기능 | 내용 | 더 나은 점 |
|---|---|---|
| **시간표** | 과목 검색·추가, 강의실, 시간 | 홈에 **"다음 수업 15:00 성결관 301"** 카드 |
| **강의평** | 별점, 과제·시험·출석 스타일, 한 줄 평 | 강의평 작성 = **가장 큰 기여** (4층) |
| **학식** | 오늘 메뉴 | 학생이 올린 **오늘 사진 + 평점** |
| **공지 요약** | 학교 홈페이지 공지를 짧게 요약 | 학사·장학 공지를 놓치지 않음 |
| **D-day** | 시험, 과제, 수강신청 | 시간표와 학사일정에 연동 |

### 강의 데이터를 어떻게 모으나 (MVP 전 첫 숙제)
| 방법 | 장점 | 단점 |
|---|---|---|
| 공개된 수강편람·강의시간표 정리 | 정확함 | 공개 여부 확인 필요, 학기마다 갱신 |
| **학생이 시간표에 직접 입력 → 과목 DB로 합치기** | 학교 협조 없이 가능 | 초기에 중복·오타 정리 필요 |
| 학교와 제휴 | 가장 정확 | 파일럿 단계에서는 어려움 |

→ **추천**: 파일럿은 공개 자료가 있으면 그것으로 기본 과목 목록을 만들고, 없으면 학생 입력으로 쌓는다. 학교 포털에 로그인해서 정보를 긁어오는 방식은 쓰지 않는다 (이용약관·보안 문제).

## 2층. 머무를 이유 (콘텐츠·소통)

| 기능 | 내용 |
|---|---|
| **게시판** | 자유, 정보, 고민(항상 익명), 학과별 게시판 |
| **질문 & 답변** | 수업, 교수님, 학사, 생활 질문. 질문자가 답변을 **채택**하면 답변자 기여 상승 |
| **지금 캠퍼스** | 학생 실시간 제보: "도서관 3층 자리 많음", "학식 줄 김", "셔틀 방금 출발", "OO관 앞 행사 중". 산 위에 아이콘으로 표시, 1~2시간 뒤 사라짐. 다른 학생이 "도움 됨"을 누르면 제보자 기여 상승 |
| **핫글** | 반응이 많은 글. 홈 카드와 산 위 말풍선에 노출 |
| **학과 라운지** (v1) | 같은 학과(같은 동물)끼리만 보이는 공간. 중턱이 열리면 라운지를 꾸밀 수 있음 |

---

## 3층. 사람 연결 (네트워크 효과)

사용자가 많을수록 좋아지는 기능이다. 한번 자리 잡으면 다른 앱으로 옮기기 어렵다.

| 기능 | 내용 | 단계 |
|---|---|---|
| **장터** | 전공책, 자취 용품 중고거래. 교내 직거래, 앱 안 결제 없음. 거래 완료 후기 | MVP |
| **스터디·팀플 매칭** | 과목별 모집, 인원·시간 조건 | v1 |
| **같이 밥·택시** | 시간·장소 정하고 모집, 정원 차면 마감 | v1 |
| **분실물** | 사진, 위치(산 위 표시) | v1 |
| **동아리 거리** | 동아리·행사 홍보 | v1 |

## 5층. 나를 표현

| 기능 | 내용 | 단계 |
|---|---|---|
| 학과 동물 캐릭터 | 학교 색 후드, 무늬·표정 | MVP |
| 등산 장비 | 등급별 모자, 배낭, 지팡이, 깃발 | MVP 기본형 |
| 칭호 | "강의평 장인", "정보통", "답변왕" | v1 |
| 정상 깃발 | 시즌마다 정상 깃발에 기여 상위자 이름 (공개 동의한 사람만) | v1 |
| 코인 상점 | 옷, 소품 | v1 |

## 하루 사용 흐름 (예시)

| 시간 | 행동 | 층 |
|---|---|---|
| 08:40 | 앱 열기 → "다음 수업 9시 영암관" 확인 | 1 |
| 11:50 | 학식 사진 확인, 줄 길다는 제보 보고 매점으로 | 1, 2 |
| 13:00 | 질문 게시판에 "OO 교수님 중간고사 범위?" 답변 → 채택 +25 | 2, 4 |
| 16:30 | 도서관 3층 자리 많다고 제보 → "도움 됨" 8개 | 2, 4 |
| 21:00 | 장터에서 전공책 거래 약속 | 3 |
| 23:00 | 산 보기: "산길까지 3%!", 학과 등반대 2위 | 4 |
