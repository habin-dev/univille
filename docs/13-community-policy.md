# 13. 커뮤니티 정책: 익명성 & 운영

> 대학 커뮤니티는 결국 **분위기**로 살고 죽는다. 귀여운 섬이어도 게시판이 날카로우면 아무도 남지 않는다.

## 1. 익명성 설계

### ⚠️ 발견한 문제: 학과 동물이 익명을 깰 수 있다
학과마다 동물이 정해져 있기 때문에, 익명 글에 동물을 그대로 보여주면 **작은 학과는 사실상 신원이 드러난다.**
예를 들어 성결대에서 🐧 펭귄은 유아교육과, 🐆 치타는 체육교육과 하나뿐이다. "익명 펭귄"이 쓴 글은 "유아교육과 누군가"가 된다.

### 추천안
| 위치 | 보이는 것 |
|---|---|
| **섬 위의 내 캐릭터** | 학과 동물 + 학교 색 (섬에서의 정체성) |
| **익명 글·댓글** (기본값) | **"익명 섬주민"** 공통 아바타 (동물 실루엣). 학과 정보 없음 |
| 글쓴이가 원할 때 | "학과 동물 공개" 체크 → 동물 표시 (예: 학과 정보 공유 글) |
| 한 글 안의 댓글 | 익명1, 익명2… 번호, 글쓴이는 "글쓴이" 표시 |
| 비동기 주민 말풍선 | 글 제목만. **어느 주민이 썼는지와 연결하지 않음** |
| 학과 대항 순위 | 학과 단위 합계만 공개. 개인 기여 TOP 순위는 **본인이 공개를 켠 경우만** 표시 |

- 학과 인원이 적은 경우(예: 인증 학생 30명 미만) 학과 대항에서도 **인접 학과와 묶어서** 표시한다 ([03 문서](03-activity-score.md)).
- 서버에는 작성자가 기록되지만, 다른 사용자에게는 노출하지 않는다. 운영자 조회는 신고 처리와 법적 요청에만 쓰고 기록을 남긴다.

## 2. 게시판별 성격

| 게시판 | 익명 | 학과 동물 공개 | 비고 |
|---|---|---|---|
| 광장 (자유) | 기본 익명 | 선택 | |
| 도서관 (정보) | 기본 익명 | 선택 (권장 안내) | 학과 정보 글은 공개하면 신뢰도 ↑ |
| 장터 (중고거래) | 닉네임 | — | 거래 상대 확인을 위해 닉네임, 교내 직거래 원칙 |
| 동아리 거리 (홍보) | 동아리 계정/닉네임 | — | 홍보 주체가 분명해야 함 |
| 카페 (고민 상담) | **항상 익명** | 불가 | 민감한 이야기를 하는 곳 |

## 3. 운영 원칙

### 금지 행위
비방·혐오 표현, 특정인 저격·신상 공개, 성적 콘텐츠, 불법 거래, 도배·광고, 시험 부정행위 공모, 다른 학교·학과 비하 (대항전 과열 방지)

### 처리 흐름
```
신고 접수 ─→ (신고 N건 이상 or 필터 감지) 자동 블라인드 ─→ 운영자/섬지기 검토 ─→ 유지 or 삭제 + 제재
```

| 단계 | 제재 |
|---|---|
| 1회 | 경고 + 해당 글 삭제 |
| 2회 | 글쓰기 7일 정지 |
| 3회 | 글쓰기 30일 정지 |
| 중대한 위반 (신상 공개, 불법) | 즉시 영구 정지 |

- 제재받은 사용자의 벽돌은 학과·학교 점수에서 빠진다. 대항전 때문에 무리하는 행동을 막는다.
- 모든 사용자는 다른 사용자를 **차단**할 수 있다 (그 사람 글·댓글이 안 보임).

### 섬지기 (학생 운영진)
- 학교별 5~10명, 한정 칭호와 섬 장식 보상
- 권한: 블라인드 글 1차 검토, 공지 작성, 이벤트 진행
- 권한 없음: 사용자 신원 조회, 영구 정지 (운영자만)
- 섬지기의 처리 기록은 운영자가 확인할 수 있다

## 4. 출시 전 법적 체크리스트

> 아래는 준비할 항목 목록이다. **출시 전에 전문가(변호사 등)에게 검토를 받는다.**

- [ ] 이용약관, 운영정책 공개
- [ ] 개인정보처리방침: 수집 항목 최소화 (학교 메일은 인증 후 원문 대신 해시 보관 검토), 보관 기간, 파기 절차
- [ ] 권리침해 게시물 신고 및 임시조치 절차 (정보통신망법 관련)
- [ ] 저작권 침해 신고 절차
- [ ] 장터: 앱 안에서 결제하지 않고 직거래만 연결 (결제를 붙이면 별도 검토 필요)
- [ ] 만 14세 미만 가입 제한 (대학생 대상이지만 명시)
- [ ] 학교 명칭·건물 외관 사용 범위: 로고·교표·공식 캐릭터는 쓰지 않음 ([10 문서](10-pilot-sungkyul.md))
- [ ] 앱스토어 출시 시: 사용자 생성 콘텐츠 앱에 요구되는 신고·차단·필터 기능 확인
