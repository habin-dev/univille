# 12. 리스크 & 결정

## 1. 리스크

### 제품
| 리스크 | 영향 | 대응 |
|---|---|---|
| **실용 기능이 지금 쓰는 앱보다 못함** | 옮겨 올 이유가 없음 | 1층을 MVP 최우선, "오늘 수업 카드"처럼 한 가지라도 더 편하게 |
| **강의 데이터를 못 모음** | 시간표·강의평이 안 돌아감 | Step 0에서 먼저 해결 ([09](09-mvp-and-validation.md)) |
| **"공사 중"이 "아직 안 됨"으로 느껴짐** | 미완성 앱 인상 | 첫날부터 임시 천막에서 모든 기능 사용, 사전예약 벽돌로 오픈 첫날 공사 진행 ([02](02-campus-world.md)) |
| **기여가 노동처럼 느껴짐** | 숙제 피로 | 오늘의 목표는 3개만, 출석 알림은 기본 꺼짐 |
| **다 지은 뒤 할 게 없음** | 장기 이탈 | 꾸미기, 시즌 장식, 증축, 캠퍼스 투어 ([02](02-campus-world.md)) |
| **고인물 문화** | 새내기 이탈 | 혜택은 편의·꾸미기만, 개인 순위 기본 비공개 ([05](05-rewards.md)) |
| **벽돌 노린 저품질 글** | 분위기·신뢰 하락 | 다른 사람이 인정한 행동에 높은 점수, 하루 상한, 회수 ([04](04-contribution.md)) |
| **학과 동물로 익명이 깨짐** | 작은 학과 신원 노출 | 익명 글은 공통 아바타 ([07](07-community-policy.md)) |
| **운 요소가 도박처럼 보임** | 심의 등급 상승, 학교 협력 어려움, 기여 공정성 훼손 | 벽돌을 걸거나 잃는 구조 금지, 오락실은 무료·보상형만 ([15](15-arcade.md)) |
| **경쟁 과열** | 비방 | 비하 제재, 협력 이벤트, 다양한 기준의 상 ([06](06-competition.md)) |

### 기술 & 아트
| 리스크 | 대응 |
|---|---|
| 3D 성능 (저사양 폰) | 성능 등급, "한눈에" 2D 홈을 기본값으로, 한눈에 화면에서는 3D 렌더링 정지 |
| OSM 건물 데이터 부족·부정확 | 운영 도구로 보완, 필요한 건물만 직접 추가 |
| 자동 생성 건물이 밋밋함 | 외벽·지붕 프리셋 품질에 투자, 역할별 간판·소품으로 개성 |
| 3D 아트 비용 | 공통 프리셋 재사용, 랜드마크만 학교별 |
| 특정 게임과 비슷해 보임 | 오리지널 디자인, 특정 게임의 캐릭터·에셋·명칭 미사용 |

### 운영 & 법
| 리스크 | 대응 |
|---|---|
| 1인 운영 부담 | 자동 블라인드, 현장소장단, 처리 기준 문서화 |
| 강의평의 명예훼손 소지 | 수업에 대한 평가로 한정, 신고 시 임시조치 |
| 실제 건물 외관 사용 | 로고·교표 없이 외관을 단순화한 오리지널 모델만 |
| 공지·학교 자료 이용 | 공개 자료만, 출처 링크, 포털 로그인 수집 금지 |
| 개인정보 | 최소 수집, 해시 보관 검토, 법률 검토 |

## 2. 결정 완료

- [x] 기능은 첫날부터 임시 천막에서 전부 사용, 완공되면 건물로 이사

- [x] 혜택은 편의·꾸미기·신뢰 표시만
- [x] 학생회관 숨은 오락실: 벽돌을 걸지 않는 무료·보상형 놀이만 ([15](15-arcade.md))
