# 12. 리스크 & 결정

## 1. 리스크

### 제품
| 리스크 | 영향 | 대응 |
|---|---|---|
| **실용 기능이 지금 쓰는 앱보다 못함** | 옮겨 올 이유가 없음 | 1층을 MVP 최우선, "오늘 수업 카드"처럼 한 가지라도 더 편하게 |
| **강의 데이터를 못 모음** | 시간표·강의평이 안 돌아감 | Step 0에서 먼저 해결 ([09](09-mvp-and-validation.md)) |
| **안개가 "잠금"으로 느껴짐** | 짜증, 이탈 | 기본 기능은 절대 잠그지 않음. 안개 너머는 덤만 ([02](02-mountain-world.md)) |
| **기여가 노동처럼 느껴짐** | 숙제 피로 | 오늘의 등반은 3개만, 출석 알림은 기본 꺼짐 |
| **고인물 문화** | 새내기 이탈 | 혜택은 편의·꾸미기만, 개인 순위 기본 비공개 ([05](05-rewards.md)) |
| **기여 노린 저품질 글** | 분위기·신뢰 하락 | 다른 사람이 인정한 행동에 높은 점수, 하루 상한, 회수 ([04](04-contribution.md)) |
| **학과 동물로 익명이 깨짐** | 작은 학과 신원 노출 | 익명 글은 공통 아바타 ([07](07-community-policy.md)) |
| **경쟁 과열** | 비방 | 비하 제재, 협력 이벤트, 다양한 기준의 상 ([06](06-competition.md)) |

### 기술 & 아트
| 리스크 | 대응 |
|---|---|
| 3D 성능 (저사양 폰) | 성능 등급, 리스트 모드, 홈 미니 산은 가볍게 |
| 부지 윤곽 데이터가 없거나 이상함 | 직접 그리기, 비율 보정 |
| 3D 아트 비용 | 공통 장소 에셋 재사용, 랜드마크만 학교별 |
| 특정 게임과 비슷해 보임 | 오리지널 디자인, 특정 게임의 캐릭터·에셋·명칭 미사용 |

### 운영 & 법
| 리스크 | 대응 |
|---|---|
| 1인 운영 부담 | 자동 블라인드, 셰르파단, 처리 기준 문서화 |
| 강의평의 명예훼손 소지 | 수업에 대한 평가로 한정, 신고 시 임시조치 |
| 공지·학교 자료 이용 | 공개 자료만, 출처 링크, 포털 로그인 수집 금지 |
| 개인정보 | 최소 수집, 해시 보관 검토, 법률 검토 |

## 2. 결정 완료
- [x] 목적: 전국 대학생이 지금 쓰는 대학 커뮤니티 대신 쓰는 플랫폼
- [x] 배경: **캠퍼스 부지 모양의 산**, 베이스캠프에서 시작, 위쪽은 안개
- [x] 기능 구성: **5개 층** (매일 열 이유 → 머무를 이유 → 연결 → 다시 올 이유 → 표현)
- [x] 기본 기능은 절대 잠그지 않음
- [x] 기여 = 다른 학생에게 도움이 된 행동
- [x] 혜택은 편의·꾸미기·신뢰 표시만
- [x] 캐릭터: 학과별 동물, 학교별 옷 색
- [x] 파일럿: 성결대학교 ([13](13-pilot-sungkyul.md))

## 3. 결정 대기
| 질문 | 추천안 |
|---|---|
| 안개 해금 주체 | **학교 공동** (지도) + **개인** (혜택) — 현재 문서 기준 |
| 걷힌 안개 유지 여부 | **유지** + 시즌마다 계절 봉우리 — 현재 문서 기준 |
| 강의 데이터 확보 | 공개 자료 우선, 없으면 학생 입력 |
| 서비스 이름 | 가칭 "캠퍼스산", 후보 검토 ([01](01-vision.md)) |
| 3D 아트 | 캐릭터·랜드마크 외주, 소품 직접 |
| 공식 마스코트 '스쿠아' 제휴 | 파일럿 반응 후 제안 |
| 성결대 재학생 수 (N) | 대학알리미로 확인 |
| 기여 점수표, 안개 기준 수치 | 파일럿 데이터로 보정 |
