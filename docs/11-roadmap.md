## Phase 1. MVP 개발 (12~14주)
| 주차 | 개발 | 아트 (병행) |
|---|---|---|
| 1~2 | 세팅 (Next.js, Supabase), 메일 인증, 학과 선택, DB, 이벤트 로깅 | 캐릭터 기본 모델 |
| 3~4 | **시간표** (과목 DB, 검색, 오늘 수업 카드), 학사 D-day | 동물 10종 파츠 |
| 5~6 | **강의평**, 학식 사진·평점 | 건축 장비 2종 |
| 7 | 게시판, 질문 & 답변, 익명 정책 | 임시 천막 세트 |
| 8 | 지금 캠퍼스 제보, 장터 | 제보 아이콘 |
| 9 | 벽돌 엔진, 건물 완공 판정, 학과 건축팀·학과 하우스, 오늘의 목표 | 공사 소품 (비계, 크레인, 굴착기) |
| 10~11 | 3D 캠퍼스 (OSM → 건물 자동 생성, 공사 단계 클리핑, 홈 미니 캠퍼스, 전체 화면 조작, 비동기 주민), 성능 등급, 리스트 모드 | 재림관 랜드마크, 외벽·지붕 프리셋 |
| 12 | 관리자 페이지, 신고·차단·자동 블라인드 | 완공 연출 |
| 13~14 | QA, 저사양 테스트, 약관·개인정보처리방침, 법률 검토, 오픈 | 공유 카드 이미지 |

**오픈 시점 목표: 학기 시작 2~3주 전** (시간표·수강신청 시즌)

## Phase 2. 파일럿 운영 & v1 (오픈 후 3개월)
- 8주 운영 → [성공 기준](09-mvp-and-validation.md) 판단
- 공지 요약, 스터디·팀플 매칭, 같이 밥·택시, 분실물, 동아리 거리
- 건축가·총괄 건축가 등급, 현장소장단, 코인 상점
- 건물 안 공간, 꾸미기, 시즌 장식, 증축
- 실시간 접속자
- 인접 학교 2~3곳 오픈 → 학교 대항, 캠퍼스 투어
- Capacitor 앱 출시, 푸시 알림

## Phase 3. 확장 (6~12개월)
- 학교 오픈 신청 → 캠퍼스 생성·랜드마크 제작 자동화, 30개 학교
- 자매 캠퍼스, 리그
- 수익화 실험
