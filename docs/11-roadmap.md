- [x] 기능 구조: 5개 층 ([03](03-features.md))
- [x] 파일럿 학교: 성결대학교 (학과 → 동물, 랜드마크 재림관)

## Phase 1. MVP 개발 (12~14주)
| 주차 | 개발 | 아트 (병행) |
|---|---|---|
| 1~2 | 세팅 (Next.js, Supabase), 메일 인증, 학과 선택, DB, 이벤트 로깅 | 캐릭터 기본 모델 |
| 3~4 | **시간표** (과목 DB, 검색, 오늘 수업 카드), 학사 D-day | 동물 10종 파츠 |
| 5~6 | **강의평**, 학식 사진·평점 | 등급 장비 2종 |
| 7 | 게시판, 질문 & 답변, 익명 정책 | 베이스캠프·산길 장소 |
| 8 | 지금 캠퍼스 제보, 장터 | 제보 아이콘 |
| 9 | 기여도 엔진, 안개 해금, 학과 등반대, 오늘의 등반 | 안개, 해금 연출 |
| 10~11 | 3D 산 (부지 → 지형 생성, 홈 미니 산, 전체 화면 조작, 비동기 주민), 성능 등급, 리스트 모드 | 재림관 랜드마크 |
| 12 | 관리자 페이지, 신고·차단·자동 블라인드 | |
| 13~14 | QA, 저사양 테스트, 약관·개인정보처리방침, 법률 검토, 오픈 | 공유 카드 이미지 |

**오픈 시점 목표: 학기 시작 2~3주 전** (시간표·수강신청 시즌)

## Phase 2. 파일럿 운영 & v1 (오픈 후 3개월)
- 8주 운영 → [성공 기준](09-mvp-and-validation.md) 판단
- 공지 요약, 스터디·팀플 매칭, 같이 밥·택시, 분실물, 동아리 거리
- 가이드·셰르파 등급, 셰르파단, 코인 상점
- 중턱·전망대·정상 콘텐츠, 계절 봉우리
- 실시간 접속자
- 인접 학교 2~3곳 오픈 → 학교 대항
- Capacitor 앱 출시, 푸시 알림

## Phase 3. 확장 (6~12개월)
- 학교 오픈 신청 → 부지·랜드마크 제작 자동화, 30개 학교
- 자매 산, 리그
- 수익화 실험
