# 11. 핵심 루프 & 보상 설계

> 사람들이 **왜 매일 다시 들어오는지**를 정한다. 기능 목록보다 이 루프가 먼저다.

## 1. 루프 한눈에 보기

```
 매일 (1~5분)                매주                     시즌 (4주)              학기
 ─────────────              ─────────────            ─────────────          ─────────────
 출석 → 벽돌 1개             월요일: 학과 대항 결과      랜드마크 단계 상승        축제 / 시험기간
 섬 한 바퀴 (주민 말풍선)      1위 학과 동상 세움          시즌 보상 (섬 주민 전원)   특별 이벤트
 핫글 확인 → 댓글·공감         주간 미션 3개              섬 땅 넓어짐             방학 리그
 일일 미션 3개 → 벽돌·코인      내 학과 순위 알림           (학교 2개 이상부터) 리그 순위
```

| 주기 | 사용자가 느끼는 것 | 핵심 장치 |
|---|---|---|
| 매일 | "들어가면 뭔가 바뀌어 있다" | 출석, 주민 말풍선(실제 최신 글), 일일 미션 |
| 매주 | "우리 학과가 이겼으면 좋겠다" | 학과 대항, 1위 학과 동상 |
| 시즌 | "우리 학교 재림관이 자란다" | 랜드마크 7단계, 시즌 보상 |
| 학기 | "학교생활과 같이 간다" | 축제·시험기간 이벤트 |

## 2. 매일 루프 (가장 중요)

1. **앱 열기** → 내 동물 캐릭터가 섬에 서 있음. 우측 상단 출석 버튼에 빨간 점.
2. **출석** → 벽돌이 재림관으로 날아감 (벽돌 +1).
3. **섬 한 바퀴** → 주민들 말풍선에 **실제 최신 글 제목**이 떠 있음. 궁금한 말풍선을 누르면 그 글로 이동.
4. **핫글 확인** → 광장 앞 게시판에 오늘의 HOT 3개.
5. **반응** → 댓글, 공감 → 벽돌·코인 획득.
6. **일일 미션 완료** → 보너스.

**목표 체류 시간은 길지 않다.** 하루 3~5분, 대신 **매일** 오게 만드는 것이 목표다.

### 일일 미션 예시 (매일 3개, 무작위)
| 미션 | 보상 |
|---|---|
| 광장 글에 댓글 1개 | 벽돌 1 · 코인 10 |
| 다른 학과 주민의 글에 공감 3개 | 벽돌 1 · 코인 10 |
| 도서관 정보글 1개 읽기 | 코인 10 |
| 주민 1명에게 말 걸기 | 코인 5 |
| 섬에서 숨은 조개껍데기 찾기 | 코인 15 |

## 3. 두 가지 재화

| | 🧱 **벽돌** | 🪙 **코인** |
|---|---|---|
| 성격 | **공동 자원**. 쌓으면 우리 학교 재림관이 자람 | **개인 자원**. 나를 꾸미는 데 씀 |
| 얻는 법 | 출석, 유효한 글·댓글·받은 공감, 미션 | 미션, 활동, 시즌 보상 |
| 쓰는 곳 | 자동으로 랜드마크에 쌓임 (개인이 쓸 수 없음) | 옷, 소품, 가구 (v1 상점) |
| 하루 상한 | 있음 (어뷰징 방지, [03 문서](03-activity-score.md)) | 있음 |
| 왜 분리하나 | 학교를 위한 기여와 나를 위한 보상을 섞으면, 꾸미기용으로 벽돌을 모으는 이기적 행동이 생김 | |

- 벽돌 수 = 개인 기여도 = 학과 대항 점수의 원천.
- 랜드마크 단계는 **개인 벽돌 합계가 아니라 [활성도 점수](03-activity-score.md)**로 정한다. 벽돌은 사용자가 체감하는 표현이고, 실제 판정은 규모가 보정된 점수로 한다.

## 4. 섬이 살아 보이게: 비동기 주민

초기에는 동시 접속자가 적다. 혼자 있는 섬은 쓸쓸하므로, **실시간 멀티플레이 없이도 섬이 북적이게** 만든다.

- 최근 24시간 안에 활동한 실제 학생들의 동물 아바타가 **주민(NPC)으로 섬을 돌아다닌다**.
- 주민 말풍선에는 **최근 올라온 글의 제목**이 뜬다. 누르면 그 글로 간다.
- 단, **말풍선과 작성자는 연결하지 않는다.** 아무 주민에게나 무작위로 글 제목을 띄운다 (익명성 보호, [13 문서](13-community-policy.md)).
- 활동이 많은 날일수록 주민 수가 늘어난다 → 랜드마크 "북적임" 상태와 같은 신호.
- 실시간 접속자 표시는 v1에서 추가한다. 그때도 비동기 주민은 유지해서 새벽에도 섬이 비지 않게 한다.

## 5. 알림 (적게, 의미 있게)

| 알림 | 빈도 | 기본값 |
|---|---|---|
| 내 글에 댓글 | 실시간 (묶어서) | 켜짐 |
| 학과 대항 주간 결과 | 주 1회 (월요일) | 켜짐 |
| 재림관 단계 상승 | 시즌에 몇 번 | 켜짐 |
| 출석 리마인드 | 하루 1회, 저녁 | **꺼짐** (사용자가 켜야 함) |
| 핫글 추천 | — | 보내지 않음 |

알림을 남발하면 대학생은 바로 끈다. **보낼 이유가 분명한 것만** 보낸다.

## 6. 첫 5분 (온보딩)

| 순서 | 화면 | 목표 |
|---|---|---|
| 1 | 학교 메일 인증 | 30초 안에 끝 |
| 2 | 학과 선택 → **내 동물 공개** 연출 | "우리 학과는 너구리!" 공유하고 싶게 |
| 3 | 섬 도착, 조작 안내 (조이스틱/탭) | 10초 튜토리얼, 건너뛰기 가능 |
| 4 | 재림관 앞으로 안내 → 첫 출석, 벽돌 날리기 | 랜드마크 개념 이해 |
| 5 | 광장 → 핫글 하나 열기 | "여기가 게시판이구나" |
| 6 | 리스트 모드 버튼 위치 알려주기 | 게임이 싫은 사람도 남게 |
