# 02. 캠퍼스 세계 & 캐릭터

## 1. 캠퍼스 부지

- 학교마다 **실제 캠퍼스 부지 윤곽**이 3D 땅이 된다.
- 실제 **건물 자리**마다 공사 부지가 있다. 처음에는 빈 터와 공사 표지판뿐이다.
- 부지 윤곽과 건물 위치·모양은 **OpenStreetMap**에서 가져온다 ([10](10-tech.md)). 데이터가 부족한 학교는 지도를 보고 직접 보완한다. OpenStreetMap은 ODbL 라이선스라 **출처 표기**가 필요하다.

```
 🚧 공사 부지 (빈 터)
 ┌──────────────────────────────────┐
 │ 📋 학술정보관 (도서관)                │
 │    벽돌 1,240 / 3,000              │
 │    강의평·정보글을 쓰면 올라가요        │
 └──────────────────────────────────┘
```

## 2. 건물 = 기능

산 컨셉에서는 "기능은 높이, 실제 건물은 풍경"으로 따로 둬야 했다. 캠퍼스 짓기에서는 **건물과 기능이 1:1로 맞는다.** 학교마다 실제 건물에 아래 **역할**을 붙인다 (성결대 예시는 [13](13-pilot-sungkyul.md)).

| 역할 | 들어가는 기능 | 이 건물을 올리는 기여 |
|---|---|---|
| 📚 **도서관** | 강의평, 정보 게시판, 도서관 자리 제보 | 강의평, 반응 많은 정보글 |
| 🏫 **강의동** (여러 개 가능) | 시간표, 오늘 수업, 수업 질문 & 답변 | 시간표 등록(첫 1회), 답변 채택. **그 수업이 열리는 강의동**에 쌓임 |
| 🍱 **학생식당** | 학식 메뉴, 사진, 평점 | 학식 사진·평점 |
| 🎪 **학생회관** | 자유 게시판, 동아리 거리, 총학 소통 + 완공 시 **숨은 오락실** ([15](15-arcade.md)) | 반응 많은 글, 동아리 홍보 |
| ☕ **상담소** | 고민 게시판 (항상 익명) | 고민 글에 도움이 된 댓글 |
| 🛍️ **정문 장터** | 중고거래 | 거래 완료 + 후기 |
| 🛏️ **기숙사** | 내 방 꾸미기, 같이 밥·택시 (v1) | 출석, 오늘의 목표 |
| 🏠 **학과 하우스** | 학과 게시판, 학과 라운지 | 그 학과 학생들의 모든 기여 일부 |
| 🏛️ **랜드마크** | 학교 공지 요약, 학사일정 + **최종 목표** | 모든 기여의 10%가 모임 |

- "지금 캠퍼스" 제보는 **제보한 장소의 건물**에 벽돌이 쌓인다 (학생식당 줄 제보 → 학생식당).
- 실제 건물이 역할보다 많으면 나머지는 **강의동, 풍경 건물**로 둔다. 역할보다 적으면 한 건물에 역할 두 개를 넣는다.
- **실제 모습보다 기능이 잘 보이는 쪽을 택한다.** 예: 학생식당이 강의동 지하에 있으면 바로 옆에 **별도 건물로 분리**한다. 건물 이름도 학생들이 실제로 부르는 이름(예: "학생 기숙사")으로 표시할 수 있다.

## 3. 임시 천막: 아무것도 잠그지 않는 방법

- 첫날, 정문 앞에 **임시 천막촌**이 있다. 도서관 천막, 학식 천막, 게시판 천막…
- **모든 기능은 천막에서 바로 쓸 수 있다.** "한눈에" 화면에서도 쓸 수 있다.
- 건물이 완공되면 천막이 **건물 안으로 이사**한다. 그때 더해지는 것:
  - 건물 안 공간 (캐릭터로 들어가서 둘러보기)
  - 건물 장식, 조명, 그 건물 전용 이벤트
  - 완공 축하 (학교 전체 알림, 테이프 커팅 연출, 건축 참여자 명판)

## 4. 공사 단계

모든 건물은 같은 단계를 거친다. 단계마다 모습이 바뀌어서 매일 들어오면 조금씩 달라져 있다.

| 단계 | 모습 | 진행도 |
|---|---|---|
| 0 | 🚧 빈 터, 공사 표지판 | 0% |
| 1 | ⛏️ 터파기, 굴착기 | 10% |
| 2 | 🏗️ 골조, 크레인 | 30% |
| 3 | 🧱 외벽이 아래층부터 올라감 | 30~90% |
| 4 | ✨ **완공** (지붕, 창문, 간판) | 100% |
| 5 | 💡 꾸미기 (조명, 화단, 벤치, 시즌 장식) | 완공 후 계속 |

- 완공 조건은 **벽돌 수 + 참여 인원** 두 가지 ([04](04-contribution.md)). 몇 명이 혼자 지을 수 없다.
- **랜드마크**는 마지막 목표다. 다른 건물이 대부분 완공될 즈음 완공되도록 기준을 맞추고, 완공되면 캠퍼스 전체 축제(불꽃놀이)가 열린다.

## 5. 끝나지 않게

| 다 지은 뒤 | 내용 |
|---|---|
| 💡 꾸미기 | 건물마다 조명, 정원, 벤치, 분수. 학교 전체 기여로 추가 |
| 🎄 시즌 장식 | 벚꽃 축제, 여름 물놀이, 가을 축제 무대, 겨울 일루미네이션 |
| 🏗️ 증축 | 새 학기마다 "별관", "옥상 정원" 같은 증축 프로젝트 |
| ✨ 황금 랜드마크 | 학교 대항 시즌 상위 학교만 |
| 🚌 캠퍼스 투어 | 다른 학교 캠퍼스 구경 (v1) |

## 6. 홈 화면: 3D 캠퍼스 + "한눈에"

홈은 두 가지이고, 하단 탭 한 번으로 오간다.

| 화면 | 역할 | 기본값 |
|---|---|---|
| **3D 캠퍼스** | 메인. 내 캐릭터로 캠퍼스를 걷고, 천막·건물에서 기능을 쓰고, 벽돌이 쌓이는 걸 본다 | 일반 기기 |
| **한눈에** | 에타처럼 게시판·학교 정보를 **한 화면에 정리**한 2D 페이지. 빨리 훑어보고 나갈 때 | 저사양 기기, 설정에서 선택 |

- **설정 > 시작 화면**: "3D 캠퍼스" / "한눈에" 중 고른다. 저사양 기기(성능 등급 낮음)는 "한눈에"가 기본이다.
- 한눈에 화면에서는 3D를 그리지 않는다 (배터리·발열 절약). 3D 에셋도 3D 탭을 처음 열 때 받는다.
- 두 화면은 **같은 기능**을 보여 준다. 3D에서만 되는 기능은 없다 (캠퍼스 걷기·건물 구경 제외).

### "한눈에" 화면 구성 (위에서 아래로)

```
┌───────────────────────────────┐
│ 우리캠  성결대학교      🏠 3D  🔔   │
│ 🔍 게시판, 강의, 학식 검색          │
│ [시간표][강의평][학식][셔틀]        │  ← 바로가기 8칸
│ [학사일정][장터][공지][오락실*]      │    *학생회관 완공 후
├───────────────┬───────────────┤
│ 다음 수업 09:00 │ 다음 셔틀 13:50 │  ← 1층: 매일 열 이유
│ 성결관 407     │ 학교 → 명학역   │
├───────────────┴───────────────┤
│ 즐겨찾는 게시판                     │  ← 2층: 게시판별 최신 글 1줄
│ 자유 · 정보 · 질문&답변 · 학과 · 고민 · 장터 │
├───────────────────────────────┤
│ HOT 게시물 (공감 10개 이상)          │
│ 지금 캠퍼스 (학생 제보, 2시간)        │
├───────────────────────────────┤
│ 오늘 학식 (코너별) · 학사일정·공지    │  ← 학교 공개 정보
├───────────────────────────────┤
│ 성결 캠퍼스 짓기 ▓▓▓▓░░ 51%        │  ← 4층: 누르면 3D로
│ 학술정보관 완공까지 18% · 학과 2위    │
├───────────────────────────────┤
│ 한눈에 │ 3D 캠퍼스 │ 시간표 │ 게시판 │ 나 │  ← 하단 탭
└───────────────────────────────┘
```

- **하단 탭 바는 모든 화면에 고정**된다 (한눈에, 3D 캠퍼스, 시간표, 게시판, 나). 3D 캠퍼스에서도 그대로 보이고, 지금 보고 있는 탭이 굵게 표시된다.
- 3D 캠퍼스의 버튼(인사, 점프, 상호작용)과 말풍선은 탭 바 위쪽에 놓는다.

### 3D 캠퍼스 조작: 터치·클릭만

| 플랫폼 | 이동 | 상호작용 |
|---|---|---|
| **앱** | 땅을 **터치**하면 그곳으로 걸어간다 | 건물·천막·친구를 **터치**하면 걸어가서 열리거나 말을 건다 |
| **웹** | 땅을 **클릭**하면 그곳으로 걸어간다 | 건물·천막·친구를 **클릭**하면 걸어가서 열리거나 말을 건다 |

- 조이스틱, WASD·방향키 이동, 단축키(E, Space)는 **쓰지 않는다**. 조작 방법이 하나뿐이라 처음 온 학생도 바로 안다.
- 시점: 앱은 **한 손가락으로 끌어서** 돌리고 두 손가락으로 확대, 웹은 드래그로 돌리고 휠로 확대한다 (캐릭터 조작이 아니라 카메라).

### 건물 확인이 번거롭지 않게
"이동"과 "확인"을 분리한다. 건물을 누르면 **기다리지 않고 바로 열리고**, 캐릭터는 그동안 알아서 걸어간다.

| 문제 | 해결 |
|---|---|
| 손가락이 조금만 움직여도 시점이 돌아가 탭이 씹힘 | 한 손가락 드래그는 회전, **16px 안에서 떼면 탭**. 누른 시간은 따지지 않음 (느린 폰에서도 탭이 씹히지 않게) |
| 탭으로 창이 열리자마자, 뒤따르는 클릭이 창의 닫기 버튼에 맞아 바로 닫힘 | 탭 직후 0.5초 동안 새 창에 들어오는 **유령 클릭을 무시** |
| 3D 건물 모양을 정확히 눌러야 함 | **이름표가 큰 버튼** (높이 44px, 주변 여백까지 눌림) + **조준 보정**: 건물·천막·친구 근처(48px 안)를 누르면 그걸 누른 것으로 처리 |
| 멀리 있는 건물은 걸어가는 동안 아무 반응 없음 | 누르는 즉시 **정보 창이 열리고**, 캐릭터는 그쪽으로 이동. 멀면 **달려서** 간다 |
| 동상·조형물도 눌러야 정보가 보임 | 건물과 똑같이 **동상 자체나 근처를 누르면 바로 정보 창** (예: 황금 비버 동상 → 이번 주 학과 건축팀 순위) |
| 화면 밖 건물은 찾기 어려움 | 왼쪽 위 **캠퍼스 카드를 누르면 건물 목록** (가까운 순, 공사 상태). 누르면 바로 열림 |
| 땅을 눌렀는데 건물 창이 계속 떠 있음 | 땅을 누르면 창이 닫히고 그곳으로 걸어감 |

- 친구(다른 학생 동물)는 예외: 가까이 가야 말을 걸 수 있으니 **걸어간 뒤** 말을 건다.
- 가까이 가면 뜨는 상호작용 버튼(예: "공사 현장 · 학술정보관")도 터치·클릭으로 누른다. 키보드는 Esc로 창 닫기만.
- 프로토타입: [`prototype/campus-3d.html`](../prototype/campus-3d.html)

## 7. 캐릭터: 학과 동물

- **학과마다 동물**, **학교마다 옷 색** (학교 대표 색 후드).
- 기여 등급에 따라 **건축 장비**가 생긴다: 안전모 → 공구 벨트 → 설계도 → 현장 깃발 ([05](05-rewards.md)).
- 무늬, 표정, 옷, 소품으로 개인 꾸미기.

### 전국 공통 계열 → 동물

| 계열 | 동물 | 계열 | 동물 |
|---|---|---|---|
| 공학 | 🦫 비버 | 사범/교육 | 🐧 펭귄 |
| IT/컴퓨터 | 🦝 너구리 | 체육 | 🐆 치타 |
| 자연과학 | 🦉 부엉이 | 예술/디자인 | 🐱 고양이 |
| 인문 | 🐑 양 | 신학/종교 | 🕊️ 비둘기 |
| 사회과학 | 🦊 여우 | 의약/간호/보건 | 🐨 코알라 |
| 경영/경제 | 🐿️ 다람쥐 | 자유전공 | 🐰 토끼 (전공을 정하면 해당 동물로 진화) |

- 학과 동물은 **캠퍼스 위의 내 모습**에 쓴다. 익명 글에는 기본으로 공통 아바타를 쓴다 ([07](07-community-policy.md)).
- 오리지널 디자인으로 만든다. 특정 게임의 캐릭터나 그림체를 따라 하지 않는다.

## 8. 다른 학생의 존재

| 단계 | 방식 |
|---|---|
| MVP | **비동기 주민**: 최근 24시간 활동한 학생들의 캐릭터가 캠퍼스를 돌아다니고 공사장에서 일함. 말풍선에 최신 글·질문 제목. 말풍선과 실제 작성자는 연결하지 않음 |
| v1 | 실시간 접속자: 지금 접속한 학생 캐릭터가 실제로 움직임, 이모지 반응 |
