## 4. 성결산 구성

### 정상 랜드마크: 재림관 ✅
캠퍼스에서 가장 높은 10층 건물로 총장실이 있다. 흰 외벽과 **양 끝의 원통형 타워**가 특징이라 귀엽게 만들기 좋다. 처음에는 안개 속 실루엣, 정상이 열리면 공개된다.

### 실제 건물은 풍경으로
캠퍼스투어 페이지의 건물을 산 곳곳에 **풍경**으로 둔다. 기능은 고도 구역에 붙는다 ([02](02-mountain-world.md)).

| 실제 건물 | 공식 안내의 주요 시설 | 산에서 |
|---|---|---|
| 재림관 | 총장실, 행정 부서 | ⛰️ 정상 랜드마크 |
| 학술정보관 | 도서관 | 베이스캠프 풍경, "지금 캠퍼스" 도서관 자리 제보 위치 |
| 중생관 | 학생식당, 매점 | 베이스캠프 풍경, 학식 위치 |
| 학생회관 | 총학생회, 동아리실, 체육관 | 산길 풍경, 동아리 거리 |
| 성결관 | IT 계열 실습실 | 너구리·비버 등반대 깃발 |
| 영암관 | 강의실, 피아노 실습실 | 고양이 등반대 깃발 |
| 신유관 | 기숙사 | 중턱 캠핑장 옆 |
| 기념관, 유치원 | — | 풍경 |

## 5. 공식 마스코트 '스쿠아'

성결대는 2026년에 공식 마스코트 **스쿠아(SKUAH)**를 발표했고, **학과별 스쿠아 29종**도 배포하고 있다.

- 스쿠아는 학교 저작물이므로 **허가 없이 쓰지 않는다.**
- 추천: 우리 동물 캐릭터로 개발하고, 파일럿 반응이 좋으면 학교 홍보팀·총학생회에 제휴를 제안한다. 예: 스쿠아가 베이스캠프 안내자로 등장.

## 6. 파일럿 일정 포인트
- **오픈: 학기 시작 2~3주 전** (시간표·수강신청 시즌)
- 오픈 전: 사전예약 + 강의평 씨앗 모으기 + 학과 동물 카드
- 셰르파단: 학과마다 1명 이상 모집
