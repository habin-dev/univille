# 05. 보상 & 혜택

## 1. 원칙

> **혜택은 "편해지거나 예뻐지는 것"만 준다. 다른 사람보다 위에 서는 힘은 주지 않는다.**

| ✅ 주는 것 | ❌ 주지 않는 것 |
|---|---|
| 편의 (임시저장, 예약, 알림) | 내 글이 더 위에 보이는 노출 우선권 |
| 꾸미기 (장비, 칭호, 옷) | 투표·신고에 더 큰 힘 |
| 신뢰 표시 (배지) | 다른 사람 글을 막거나 지우는 권한 (운영진 제외) |
| 먼저 써보기 (새 기능, 이벤트) | 기본 기능 이용 자격 |

이유: 혜택이 힘이 되면 "고인물" 문화가 생기고, 새로 온 학생이 떠난다.

## 2. 개인 등급 (누적 기여, 줄어들지 않음)

| 등급 | 누적 기여 (초안) | 장비 | 혜택 |
|---|---|---|---|
| 🥾 **등산객** | 0 | 기본 모자 | 모든 기본 기능 |
| 🎒 **산악인** | 300 | 배낭 | 임시저장 늘리기, 글 예약, 키워드 알림 3개 |
| 🧭 **가이드** | 1,500 | 나침반·지팡이 | 질문 답변에 **가이드 배지**, 장터 **신뢰 배지**, 키워드 알림 10개 |
| 🏔️ **셰르파** | 5,000 | 등산 깃발 | 학생 운영진(셰르파단) 지원 자격, 새 기능 먼저 써보기, 시즌 한정 장비 |

- 등급은 **다른 사람에게 장비로만 보인다** (숫자, 순위는 본인 선택으로 공개).
- 익명 글에는 등급이 보이지 않는다. 가이드 배지는 질문 답변과 장터처럼 **신뢰가 필요한 곳에서만** 본인이 켜면 보인다.

## 3. 학교 보상 (안개 해금)

산이 열리면 **학교 전체**가 받는다. 기여를 안 한 학생도 받지만, 등반에 참여한 학생은 추가로 받는다.

| 구역이 열리면 | 전체 | 등반대원 (이번 구역에 기여한 학생) |
|---|---|---|
| 산길 | 산길 장소들, 산길 테마 배경 | 한정 배지 "산길 개척" |
| 중턱 | 학과 라운지 꾸미기, 캠핑장 | 한정 장비 |
| 전망대 | 다른 학교 산 구경, 전국 게시판 | 망원경 소품 |
| 정상 | **학교 대표 건물 공개**, 정상 불꽃놀이 | 정상 깃발에 이름 (공개 동의 시) |

## 4. 오늘의 등반 (일일 목표)

매일 3개, 그날 상황에 맞게 나온다. 전부 완료하면 기여 +10.

| 예시 | 언제 나오나 |
|---|---|
| 들은 과목 강의평 1개 쓰기 | 강의평이 없는 과목을 듣고 있을 때 |
| 답변 기다리는 질문에 답하기 | 내 학과 질문이 밀려 있을 때 |
| 오늘 학식 평점 남기기 | 점심시간 |
| 지금 캠퍼스 제보 1개 | 학교에 있을 시간 |
| 핫글에 댓글 1개 | 항상 |

## 5. 시즌 보상 (4주)

| 대상 | 보상 |
|---|---|
| 학교 대항 상위 (v1) | 학교 전원에게 시즌 한정 장비, 산에 우승 깃발 |
| 주간 학과 등반대 1위 | 산 위에 학과 동물 동상 (1주), 학과원 전원 칭호 |
| 개인 기여 상위 | 정상 깃발에 이름 (공개 동의 시), 시즌 칭호 |
| 꾸준함 (시즌 중 20일 이상 출석) | 시즌 장비 |
