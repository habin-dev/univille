# 05. 보상 & 혜택

## 1. 원칙

> **혜택은 "편해지거나 예뻐지는 것"만 준다. 다른 사람보다 위에 서는 힘은 주지 않는다.**

| ✅ 주는 것 | ❌ 주지 않는 것 |
|---|---|
| 편의 (임시저장, 예약, 알림) | 내 글이 더 위에 보이는 노출 우선권 |
| 꾸미기 (장비, 칭호, 옷) | 투표·신고에 더 큰 힘 |
| 신뢰 표시 (배지) | 다른 사람 글을 막거나 지우는 권한 (운영진 제외) |
| 먼저 써보기 (새 기능, 이벤트) | 기본 기능 이용 자격 |

이유: 혜택이 힘이 되면 "고인물" 문화가 생기고, 새로 온 학생이 떠난다.

## 2. 개인 등급 (누적 벽돌, 줄어들지 않음)

| 등급 | 누적 벽돌 (초안) | 장비 | 혜택 |
|---|---|---|---|
| 🪖 **견습생** | 0 | 안전모 | 모든 기본 기능 |
| 🔨 **목수** | 300 | 공구 벨트 | 임시저장 늘리기, 글 예약, 키워드 알림 3개 |
| 📐 **건축가** | 1,500 | 설계도·연필 | 질문 답변에 **건축가 배지**, 장터 **신뢰 배지**, 키워드 알림 10개 |
| 🚩 **총괄 건축가** | 5,000 | 현장 깃발 | 학생 운영진(현장소장단) 지원 자격, 새 기능 먼저 써보기, 시즌 한정 장비 |

- 등급은 **다른 사람에게 장비로만 보인다** (숫자, 순위는 본인 선택으로 공개).
- 익명 글에는 등급이 보이지 않는다. 건축가 배지는 질문 답변과 장터처럼 **신뢰가 필요한 곳에서만** 본인이 켜면 보인다.

## 3. 학교 보상 (건물 완공)

건물이 완공되면 **학교 전체**가 받는다. 그 건물에 벽돌을 쌓은 학생은 추가로 받는다.

| 완공되면 | 학교 전체 | 건축 참여자 |
|---|---|---|
| 아무 건물 | 기능이 건물 안으로 이사, 건물 안 공간, 완공 축하 | 건물 앞 **명판에 이름** (공개 동의 시), 한정 배지 |
| 📚 도서관 | 열람실 공간, 시험기간 "합동 공부" 이벤트 | 책갈피 소품 |
| 🍱 학생식당 | 오늘의 메뉴 전광판, 학식 평점 랭킹 | 식판 소품 |
| 🏠 학과 하우스 | 학과 라운지 꾸미기 | 학과 깃발 |
| 🏛️ 랜드마크 | **캠퍼스 완공 축제**, 불꽃놀이, 다른 학교 캠퍼스 투어 열림 | 랜드마크 명판, 한정 장비 |

## 4. 오늘의 목표 (일일)

매일 3개, 그날 상황에 맞게 나온다. 전부 완료하면 벽돌 +10.

| 예시 | 언제 나오나 |
|---|---|
| 들은 과목 강의평 1개 쓰기 | 강의평이 없는 과목을 듣고 있을 때 |
| 답변 기다리는 질문에 답하기 | 내 학과 질문이 밀려 있을 때 |
| 오늘 학식 평점 남기기 | 점심시간 |
| 지금 캠퍼스 제보 1개 | 학교에 있을 시간 |
| 완공 직전 건물에 벽돌 보태기 | 완공까지 5% 이하인 건물이 있을 때 |

## 5. 시즌 보상 (4주)

| 대상 | 보상 |
|---|---|
| 학교 대항 상위 (v1) | 학교 전원에게 시즌 한정 장비, 랜드마크 황금 장식 |
| 주간 학과 대항 1위 | 캠퍼스 광장에 학과 동물 동상 (1주), 학과원 전원 칭호 |
| 개인 벽돌 상위 | 랜드마크 명판에 이름 (공개 동의 시), 시즌 칭호 |
| 꾸준함 (시즌 중 20일 이상 출석) | 시즌 장비 |

## 6. 재화

| | 🧱 **벽돌** | 🪙 **코인** (v1) |
|---|---|---|
| 성격 | 내가 얼마나 도움이 됐나 = 캠퍼스를 짓는 재료 | 꾸미기용 |
| 쓸 수 있나 | 쓰지 않음. 자동으로 건물에 쌓임 | 상점에서 씀 |
| 얻는 법 | [04](04-contribution.md)의 행동 | 오늘의 목표, 시즌 보상, 완공 보상 |
| 왜 분리하나 | 꾸미기에 쓰려고 벽돌을 아끼거나 몰아 쓰는 일을 막음 | |
