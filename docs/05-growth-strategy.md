# 05. 성장 전략

> 목표는 "대학생 대부분이 쓰는 커뮤니티"지만, 커뮤니티는 **학교 하나에서 밀도가 생겨야** 살아난다. 전국에 얇게 뿌리지 말고 **학교 단위로 하나씩 점령**한다.

## 1. 핵심 문제: 콜드 스타트

글이 없으면 아무도 안 오고, 사람이 없으면 아무도 글을 안 쓴다. 특히 이미 자리 잡은 대학 커뮤니티가 있으므로 **"갈아타기"가 아니라 "같이 쓰기"**부터 시작해야 한다.

## 2. 단계별 전략

### Phase 1. 파일럿 학교 1~3곳 (0~3개월)
- **내가 다니는 학교 + 인접 학교**에서 시작
- 오픈 전 **"마을 입주 사전예약"**: 사전예약자 수가 곧 나무 성장 → 오픈 첫날부터 나무가 자라 있음
- 초기 "이장님(운영진)" 모집: 학교별 5~10명 열성 유저에게 한정 칭호, 운영 권한 일부 부여
- 동아리, 학생회와 제휴: 홍보 게시판을 무료로 제공

### Phase 2. 학교 대항전으로 확산 (3~12개월)
- **"우리 학교 마을이 아직 없어요"** 화면: 다른 학교 학생이 일정 수 이상 사전 신청하면 마을 오픈
- 오픈된 학교끼리 순위가 보이면 **"우리 학교도 해야 하는 거 아냐?"** 심리 자극
- 라이벌 학교 묶어서 동시 오픈 (예: 지역 라이벌 2개 학교 동시 런칭)

### Phase 3. 필수 기능으로 정착 (1년~)
- 시간표, 강의평, 학식 메뉴, 학사일정 등 **매일 써야 하는 기능** 추가
- 학교 생활의 "실용"까지 커버해야 진짜 주 커뮤니티가 될 수 있음

## 3. 바이럴 장치

| 장치 | 설명 |
|---|---|
| 📸 **마을 스냅샷 공유** | 우리 학교 마을, 내 아바타, 나무 상태를 예쁜 이미지로 인스타 스토리 공유 |
| 🏆 **시즌 결과 카드** | "OO대 곰 리그 2위!" 공유용 카드 자동 생성 |
| 💌 **초대 보상** | 같은 학교 친구 초대 시 양쪽에 아이템 + 나무 물 보너스 |
| 🗺️ **월드맵** | 아직 마을이 없는 학교는 빈 섬으로 표시 → 오픈 요청 유도 |

## 4. 핵심 지표

| 지표 | 의미 |
|---|---|
| 학교별 가입률 (가입자 ÷ 재학생) | 학교 내 침투율 |
| DAU / MAU | 습관이 되었는가 |
| 글 작성자 비율 | 눈팅만 하는지, 참여하는지 |
| D1 / D7 / D30 리텐션 | 재미가 지속되는가 |
| 초대 전환율 | 바이럴이 작동하는가 |
