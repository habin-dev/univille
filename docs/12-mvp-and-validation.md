# 12. MVP & 검증 계획

> 혼자 만드는 3D 서비스라서 **무엇을 만들지 않을지**가 가장 중요하다. MVP는 "다 있는 첫 버전"이 아니라 **핵심 가설을 확인하는 가장 작은 버전**이다.

## 1. 검증할 가설

| # | 가설 | 맞다면 | 틀리면 |
|---|---|---|---|
| H1 | 3D 섬과 동물 캐릭터가 **첫 방문의 재미**를 만든다 | 사전예약·가입 전환이 높다 | 섬을 가볍게 하고 게시판 중심으로 |
| H2 | 섬이 **매일 다시 오게** 만든다 | D7 리텐션이 유지된다 | 루프([11 문서](11-core-loop.md))를 다시 설계 |
| H3 | 랜드마크·학과 대항이 **글쓰기와 반응을 늘린다** | 글/댓글 작성자 비율이 높다 | 경쟁 요소 축소, 다른 동기 찾기 |
| H4 | 게임 요소가 **정보만 원하는 사람을 쫓아내지 않는다** | 리스트 모드 사용자도 잘 남는다 | 기본 화면을 리스트로 바꾸는 것 검토 |

## 2. 개발 전 검증 (Step 0, 2~3주)

코드를 많이 쓰기 전에 **성결대 학생들의 반응**부터 본다.

| 할 일 | 방법 | 통과 기준 (초안) |
|---|---|---|
| 프로토타입 체험 인터뷰 | 3D 섬 프로토타입을 성결대 학생 15~20명에게 직접 해보게 하고 인터뷰 | 절반 이상이 "출시되면 써보겠다" |
| 랜딩 페이지 + 사전예약 | 학과 동물 공개 카드 + 사전예약 폼, 에브리타임 외 채널(인스타, 학과 단톡)로 공유 | 재학생의 **3% 이상** 사전예약 |
| 학과 동물 투표 | "우리 학과 동물 마음에 들어요?" 투표 | 불만 많은 학과는 동물 재검토 |

### 인터뷰 질문
1. 지금 학교 커뮤니티는 하루에 몇 번, 무엇 때문에 들어가나요?
2. (프로토타입을 해본 뒤) 가장 재미있었던 것 / 귀찮았던 것은?
3. 섬을 돌아다니는 것과 게시판 목록 중 어느 쪽으로 글을 보고 싶나요?
4. 우리 학과 동물이 마음에 드나요? 바꾼다면?
5. 학과 대항에서 1등 하면 기분이 좋을 것 같나요? 어떤 보상이 있으면 좋겠나요?
6. 이 앱을 친구에게 보여준다면 뭐라고 설명하겠어요?

## 3. MVP 범위 (v0.1, 성결대 파일럿)

### ✅ 만든다
| 영역 | 범위 |
|---|---|
| 가입 | `@sungkyul.ac.kr` 메일 인증, 학과 선택, 학과 동물 지정 |
| 섬 | 성결 섬 1개 (고정 레이아웃), 재림관 랜드마크, 건물 6개, 선착장(장식) |
| 캐릭터 | 내 동물 조작 (조이스틱/키보드/탭 이동, 점프, 인사), 기본 꾸미기 몇 종 |
| 주민 | **비동기 주민** (최근 활동 학생 아바타 + 최신 글 말풍선) |
| 게시판 | 광장(자유), 도서관(정보), 장터, 동아리 거리, 카페(고민). 글·댓글·공감·스크랩·신고·차단 |
| 리스트 모드 | 섬 없이 게시판만 쓰는 화면 (저사양 기기 기본값) |
| 랜드마크 | 활성도 점수 → 7단계 성장, 낮/밤 |
| 루프 | 출석, 벽돌, 일일 미션 3개, 주간 학과 대항 |
| 운영 | 관리자 페이지 (신고 처리, 제재, 공지), 자동 블라인드 |
| 플랫폼 | 모바일 웹(PWA) 먼저 |

### ❌ 만들지 않는다 (v1 이후)
실시간 멀티플레이, 채팅, 코인 상점, 내 집 꾸미기, 강의평·시간표, 다른 학교 섬·월드맵, 학교 대항 리그, 앱스토어 출시, 푸시 알림(웹 푸시 제외)

> 앱스토어 출시를 미루는 이유: 심사 대응(UGC 신고·차단 기능 등)과 빌드 관리 부담을 파일럿 이후로 미루고, 모바일 웹으로 먼저 반응을 본다.

## 4. 파일럿 성공 기준 (오픈 후 8주)

성결대 재학생 수를 **N**이라 한다 (대학알리미로 확인 예정).

| 지표 | 목표 | 왜 |
|---|---|---|
| 가입자 | N의 **10%** | 커뮤니티가 굴러가는 최소 밀도 |
| D7 리텐션 | **30%** 이상 | H2 |
| 주간 활성 사용자 중 글·댓글 작성자 | **20%** 이상 | H3 |
| 리스트 모드 사용자의 D7 리텐션 | 섬 모드 사용자의 70% 이상 | H4 |
| 하루 새 글 수 | 30개 이상 | 들어왔을 때 볼 게 있는가 |
| 신고 처리 시간 | 24시간 이내 | 분위기 관리 |

### 방향 전환 기준
- D7 리텐션이 **15% 미만**이면 기능 추가를 멈추고, 이탈한 사용자 10명을 인터뷰한다.
- 리스트 모드 사용 비율이 **80%를 넘으면** 섬은 "가끔 놀러 가는 곳"으로 두고 기본 화면을 게시판으로 바꾼다.
- 가입이 목표의 절반에 못 미치면, 2번째 학교를 열기 전에 성결대 안에서 원인을 먼저 찾는다.

## 5. 측정할 이벤트

| 이벤트 | 용도 |
|---|---|
| `signup_completed` (학과) | 가입 전환, 학과별 분포 |
| `session_start` (섬 모드 / 리스트 모드, 기기 성능 등급) | H4, 성능 문제 확인 |
| `attendance` | 매일 루프 |
| `post_created`, `comment_created`, `reaction_added` | H3, 활성도 |
| `bubble_tapped` (주민 말풍선 → 글) | 비동기 주민이 효과가 있는지 |
| `npc_talk`, `jump`, `wave` | 섬 놀이 요소를 실제로 쓰는지 |
| `mission_completed` | 일일 미션 난이도 조정 |
| `list_mode_toggled` | H4 |
| `report_created`, `report_resolved` | 운영 |

> 이벤트에는 학교, 학과, 익명 사용자 ID만 담고, 글 내용이나 이메일은 담지 않는다.
