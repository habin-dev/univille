# 07. 로드맵

> 1인 개발 기준 예상 일정. 3D 아트는 개발과 병행해서 외주 또는 직접 제작한다.

## Phase 0. 기획 & 검증 (지금 ~ 3주)
- [x] 아이디어 정리, 기획 문서 작성
- [x] 공간 컨셉: 학교별 3D 섬 + 중심 랜드마크
- [x] 캐릭터: 학과별 동물 + 학교별 색상, 직접 조작
- [x] 파일럿 학교: 성결대학교 (랜드마크 재림관, 학과 → 동물 매핑)
- [x] 3D 섬 프로토타입 ([prototype/island-3d.html](../prototype/island-3d.html))
- [x] 핵심 루프, MVP 범위, 커뮤니티 정책 정리 ([11](11-core-loop.md), [12](12-mvp-and-validation.md), [13](13-community-policy.md))
- [ ] 성결대 학생 15~20명 프로토타입 인터뷰
- [ ] 랜딩 페이지 + 사전예약 + 학과 동물 공개 카드
- [ ] 서비스 이름 확정
- [ ] 아트 방향 확정 (무드보드, 외주 여부)

## Phase 1. MVP 개발 (10~12주)
| 주차 | 개발 | 아트 (병행) |
|---|---|---|
| 1~2 | 프로젝트 세팅 (Next.js, Supabase), 학교 메일 인증, DB 스키마, 이벤트 로깅 | 캐릭터 기본 모델 1종 |
| 3~4 | 게시판 5개 + 리스트 모드 (글, 댓글, 공감, 신고, 차단, 익명 정책) | 동물 10종 머리 파츠 |
| 5~6 | 섬 화면 (R3F): 섬 데이터 로딩, 캐릭터 조작, 건물 → 게시판 연결, 성능 등급 | 공통 건물 5종 |
| 7 | 비동기 주민, 출석, 벽돌, 일일 미션 | 재림관 랜드마크 7단계 |
| 8 | 활성도 점수 배치, 랜드마크 단계, 주간 학과 대항 | 나무·꽃·소품 |
| 9 | 관리자 페이지 (신고, 제재, 공지), 자동 블라인드 | 온보딩 연출 |
| 10~12 | QA, 저사양 기기 테스트, 이용약관·개인정보처리방침, 법률 검토, 파일럿 오픈 | 마케팅 이미지 |

## Phase 2. 파일럿 운영 & v1 (오픈 후 3개월)
- 성결대 파일럿 8주 운영 → [성공 기준](12-mvp-and-validation.md) 판단
- 기준을 넘으면: 인접 학교 2~3곳 오픈 → 학교 대항 리그 시작
- 실시간 접속자 (다른 학생 캐릭터가 실제로 움직임), 이모지 반응
- 코인 상점, 내 집 꾸미기
- Capacitor로 iOS/Android 출시, 푸시 알림
- 월드맵, 선착장으로 다른 학교 섬 방문

## Phase 3. 확장 (6~12개월)
- 학교 오픈 요청 시스템, 랜드마크 제작 파이프라인, 학교 30곳
- 시간표, 강의평, 학식 메뉴
- 라이벌전, 축제 미션
- 수익화 실험 (아래)
