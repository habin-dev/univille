# 07. 로드맵

> 1인 개발 기준의 예상 일정. 아트는 병행 외주 또는 무료 에셋으로 프로토타입 후 교체.

## Phase 0. 기획 & 검증 (2~3주)
- [x] 아이디어 정리, 기획 문서 작성
- [ ] 이름, 컨셉 아트 방향 확정 (무드보드)
- [ ] 대학생 10~20명 인터뷰: "기존 커뮤니티에서 불만인 점", "마을 컨셉에 대한 반응"
- [ ] 마을 화면 Figma 목업 + 클릭 프로토타입
- [ ] 랜딩 페이지 + 사전예약 폼 → 반응 측정

## Phase 1. MVP 개발 (8~10주)
| 주차 | 작업 |
|---|---|
| 1~2 | 프로젝트 세팅 (Next.js, Supabase), 학교 이메일 인증, DB 스키마 |
| 3~4 | 게시판 (글, 댓글, 공감, 익명, 신고) |
| 5~6 | 마을 화면 (PixiJS 맵, 건물 → 게시판 연결, 아바타 기본형) |
| 7 | 활성도 점수 배치 + 학교 나무 성장 단계 |
| 8 | 출석, 순위표, 관리자 페이지 |
| 9~10 | QA, 성능 최적화, 이용약관/개인정보처리방침, 파일럿 오픈 |

## Phase 2. 파일럿 운영 & v1 (3개월)
- 파일럿 학교 1~3곳 오픈, 지표 관찰
- 실시간 접속자 표시, 이모지 반응
- 코인 & 상점, 내 집 꾸미기
- 리그 & 시즌 시스템 정식 도입
- Capacitor로 iOS/Android 앱 출시
- 전국 광장, 다른 학교 방문

## Phase 3. 확장 (6~12개월)
- 학교 오픈 요청 시스템, 학교 30곳 확장
- 시간표, 강의평, 학식 메뉴
- 라이벌전, 축제 미션 등 이벤트
- 수익화 실험 (아래 참고)

## 수익 모델 (나중에)
| 모델 | 설명 |
|---|---|
| 꾸미기 아이템 | 아바타, 가구 유료 아이템 (게임 밸런스에 영향 없는 것만) |
| 지역 광고 | 학교 주변 가게의 "마을 상점" 입점 광고 |
| 제휴 이벤트 | 기업 채용, 브랜드 콜라보 시즌 이벤트 |
| 동아리/행사 프로모션 | 홍보 게시글 상단 노출 |
