# 06. 경쟁 구조

> 경쟁은 **세 겹**이다. 학교 안(학과끼리), 학교끼리, 나 자신. 그리고 경쟁만 있으면 피곤해지므로 **협력**을 함께 둔다.

## 1. 학과 등반대 (학교 안, 매주)

- 같은 학과 학생 = 한 등반대. 깃발에 학과 동물이 그려짐.
- **이번 주 학과 기여 ÷ 학과 인증 학생 수**로 순위를 매긴다 (인원 보정).
- 인증 학생 30명 미만 학과는 같은 계열 학과와 **묶어서** 한 팀으로 (익명 보호, [07 문서](07-community-policy.md)).
- 매주 월요일 결과 발표 → 1위 학과 동물 동상이 한 주 동안 산 위에 섬.
- MVP부터 운영. 파일럿은 학교가 하나뿐이라 **학과 등반대가 핵심 경쟁**이다.

## 2. 학교 대항 (학교끼리, 시즌)

- 학교가 2개 이상 열린 뒤 시작 (v1).
- 기준은 **시즌 등반량** ([04 문서](04-contribution.md)): 누적 높이가 아니라 이번 시즌에 얼마나 올랐나. 늦게 시작한 학교도 이길 수 있다.
- 규모별 리그:

| 리그 | 재학생 수 (예시) |
|---|---|
| 🏔️ 히말라야 리그 | 2만 명 이상 |
| 🗻 알프스 리그 | 1만 ~ 2만 명 |
| ⛰️ 백두 리그 | 5천 ~ 1만 명 |
| 🌄 한라 리그 | 5천 명 미만 |

- 학교가 20개 미만일 때는 단일 리그.
- 전망대가 열린 학교는 다른 학교 산을 직접 구경할 수 있다 (구경만, 글쓰기는 불가).

## 3. 나 자신 (개인 기록)

- 개인 순위는 **기본 비공개**. 내 등급, 이번 주 기여, 지난주 대비 변화만 보인다.
- 공개를 켠 사람만 학교·학과 기여 순위에 이름(닉네임)이 나온다.

## 4. 협력 이벤트

| 이벤트 | 내용 |
|---|---|
| 🤝 **합동 등반** | 시험 기간에 학과끼리 경쟁 대신 "학교 전체 강의평 300개" 같은 공동 목표 |
| 🎉 **축제 봉우리** | 축제 기간에 계절 봉우리가 열리고, 학교 전체 미션 |
| 🧭 **새내기 가이드 주간** | 3월에 새내기 질문에 답하면 기여 2배 |
| 🏫 **자매 산** (v1) | 두 학교가 함께 목표를 채우면 양쪽 모두 보상 |

## 5. 과열 방지

- 다른 학교·학과 비하는 제재 + 기여 회수.
- 순위판은 상위권과 **우리 바로 앞뒤**만 강조. 꼴찌를 드러내지 않는다.
- "가장 많이 오른 학과", "참여 인원이 가장 늘어난 학과" 같은 **다른 기준의 상**을 같이 준다.
