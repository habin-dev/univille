# 07. 커뮤니티 정책: 익명성 & 운영

> 대학 커뮤니티는 **분위기**로 살고 죽는다. 경쟁과 캐릭터가 익명성과 분위기를 해치면 안 된다.

## 1. 익명성

### 학과 동물이 익명을 깰 수 있다
학과마다 동물이 정해져 있어서, 익명 글에 동물을 보여주면 작은 학과는 사실상 신원이 드러난다. 예: 성결대에서 🐧 펭귄은 유아교육과 하나뿐이다.

### 정책
| 위치 | 보이는 것 |
|---|---|
| 산 위의 내 캐릭터 | 학과 동물, 학교 색, 등산 장비 |
| **익명 글·댓글** (기본) | **"익명 등산객"** 공통 아바타. 학과·등급 정보 없음 |
| 글쓴이가 원할 때 | "학과 동물 공개" → 동물 표시 (학과 정보 글 등) |
| 한 글 안의 댓글 | 익명1, 익명2…, 글쓴이는 "글쓴이" |
| 질문 & 답변, 장터 | 본인이 켜면 가이드·신뢰 배지 표시 |
| 비동기 주민 말풍선 | 글 제목만. **어느 캐릭터가 썼는지 연결하지 않음** |
| 학과 등반대 순위 | 학과 합계만. 개인 순위는 공개를 켠 사람만 |

- 30명 미만 학과는 순위·통계에서 같은 계열과 묶는다.
- 서버에는 작성자가 기록되지만 다른 사용자에게는 절대 내려보내지 않는다. 운영자 조회는 신고 처리와 법적 요청에만, 기록을 남긴다.

## 2. 게시판별 성격

| 게시판 | 기본 | 비고 |
|---|---|---|
| 자유 | 익명 | 학과 동물 공개 선택 |
| 정보 | 익명 | 학과 공개 권장 안내 |
| 고민 | **항상 익명** | 공개 불가 |
| 학과 게시판 | 익명 | 같은 학과만 보임 |
| 질문 & 답변 | 익명 | 답변자는 가이드 배지 선택 표시 |
| 장터 | 닉네임 | 거래 상대 확인, 교내 직거래 |
| 동아리 거리 | 동아리 계정 | 홍보 주체가 분명해야 함 |

## 3. 운영

### 금지 행위
비방·혐오, 특정인 저격·신상 공개, 성적 콘텐츠, 불법 거래, 도배·광고, 시험 부정 공모, **기여를 노린 품앗이·허위 제보·가짜 강의평**, 다른 학교·학과 비하

### 처리
```
신고 → (신고 누적 or 필터 감지) 자동 블라인드 → 운영자 / 셰르파단 검토 → 유지 or 삭제 + 제재
```

| 횟수 | 제재 |
|---|---|
| 1회 | 경고, 해당 글 삭제, 기여 회수 |
| 2회 | 글쓰기 7일 정지 |
| 3회 | 글쓰기 30일 정지 |
| 중대 위반 (신상 공개, 불법) | 즉시 영구 정지 |

- 제재 기간의 기여는 학교·학과 점수에서 빠진다.
- 누구나 다른 사용자를 **차단**할 수 있다.

### 셰르파단 (학생 운영진)
- 셰르파 등급 중 지원자, 학교별 5~10명
- 할 수 있는 것: 블라인드 글 1차 검토, 공지, 이벤트 진행, 강의 데이터 정리
- 할 수 없는 것: 사용자 신원 조회, 영구 정지 (운영자만)
- 셰르파단 처리 기록은 운영자가 확인한다

## 4. 출시 전 법적 체크리스트

> 준비할 항목 목록이다. **출시 전에 전문가(변호사 등) 검토를 받는다.**

- [ ] 이용약관, 운영정책
- [ ] 개인정보처리방침: 최소 수집, 학교 메일은 인증 후 해시 보관 검토, 보관 기간
- [ ] 권리침해 게시물 신고·임시조치 절차 (정보통신망법 관련)
- [ ] 저작권 침해 신고 절차
- [ ] 강의평: 교수 개인에 대한 비방이 아니라 **수업에 대한 평가**로 한정하는 운영 기준
- [ ] 공지 요약: 학교 홈페이지 공개 공지만, 원문 링크 표시, 이용 조건 확인
- [ ] 장터: 직거래만 연결 (결제를 붙이면 별도 검토)
- [ ] 만 14세 미만 가입 제한
- [ ] 학교 로고·교표·공식 캐릭터 미사용
- [ ] OpenStreetMap 데이터 출처 표기 (ODbL)
- [ ] 앱스토어 출시 시: 사용자 생성 콘텐츠 앱의 신고·차단·필터 요건 확인
