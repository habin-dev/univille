# 02. 핵심 기능

## 1. 화면 구조

```
[월드맵]  바다 위에 전국 학교 섬들이 떠 있는 지도 (리그 순위, 섬 크기, 랜드마크 단계 표시)
   │
   ▼
[우리 학교 섬]  3D 섬, 내 동물 캐릭터를 직접 움직임. 중심에 학교 대표 건물 랜드마크
   ├─ 🏛️ 광장        → 자유게시판
   ├─ 📖 도서관      → 정보게시판 / 강의평
   ├─ 🛒 장터        → 중고거래 / 책 거래
   ├─ ☕ 카페        → 연애·고민 상담 (익명)
   ├─ 🎪 동아리 거리 → 동아리·행사 홍보
   ├─ 🏠 내 집       → 내 방 꾸미기, 내가 쓴 글
   ├─ 🏖️ 선착장     → 다른 학교 섬 방문, 전국 광장
   └─ 🏛️ 랜드마크   → 활성도, 이번 시즌 기여 순위, 학과 대항 순위
   │
   ▼
[게시판 화면]  일반적인 리스트/글 상세 화면 (빠르고 익숙하게)
```

- 섬은 **입구이자 분위기**이고, 실제 글 읽기, 쓰기는 **익숙한 리스트 UI**로 한다.
- **리스트 모드**: 섬을 건너뛰고 바로 게시판 목록으로 진입. 저사양 기기는 기본값

### 조작
| 기기 | 이동 | 행동 |
|---|---|---|
| 휴대폰 | 왼쪽 아래 조이스틱, 또는 땅을 탭 | 점프·인사 버튼, 건물·주민 근처에서 나타나는 "들어가기 / 말 걸기" 버튼 |
| PC | WASD·방향키, 또는 땅을 클릭 | Space 점프, E 상호작용 |
| 공통 | 드래그로 시점 회전, 휠·핀치로 확대 | 건물 이름표를 누르면 바로 게시판 미리보기 |

## 2. 기능 목록

### 🏝️ 섬 & 아바타 ([09 문서](09-island-and-avatar.md))
| 기능 | 설명 | 단계 |
|---|---|---|
| 학교별 섬 | 학교 인증 시 해당 학교 섬에 입주 | MVP |
| 랜드마크 | 섬 중심에 학교 대표 건물, 활성도에 따라 성장 | MVP |
| 동물 아바타 | 학부에 따라 동물 자동 지정, 학교 색상 적용, 무늬, 옷, 소품 커스터마이징 | MVP (기본형) |
| 캐릭터 조작 | 조이스틱·키보드·탭 이동, 점프, 인사, 건물 들어가기, 주민에게 말 걸기 | MVP |
| 비동기 주민 | 최근 활동한 학생 아바타가 섬을 돌아다니고, 말풍선에 최신 글 제목 ([11 문서](11-core-loop.md)) | MVP |
| 낮/밤 | 실제 시간에 맞춰 낮·밤, 밤에는 창문과 가로등에 불 | MVP |
| 실시간 접속자 표시 | 지금 섬에 있는 다른 학생 아바타가 보임 | v1 |
| 말풍선 반응 | 아바타끼리 이모지 반응 (텍스트 채팅은 신고 이슈로 나중에) | v1 |
| 내 집 꾸미기 | 활동 보상으로 받은 가구로 방 꾸미기, 다른 사람 방 구경 | v1 |
| 섬 날씨, 계절 | 실제 날씨, 학사일정(시험기간, 축제) 반영 | v2 |

### 📝 커뮤니티
| 기능 | 설명 | 단계 |
|---|---|---|
| 게시판 | 글, 댓글, 공감, 스크랩, 신고, 차단. 익명 정책은 [13 문서](13-community-policy.md) | MVP |
| 핫 게시글 | 공감 많이 받은 글이 광장 게시판에 표시됨 | MVP |
| 학교 인증 | 학교 이메일(@xxx.ac.kr) 인증 | MVP |
| 강의평, 시간표 | 기존 대학 커뮤니티의 필수 기능 | v1~v2 |
| 학교 간 게시판 | "전국 광장"에서 모든 학교 학생이 대화 | v1 |
| 다른 학교 섬 방문 | 선착장에서 배를 타고 다른 학교 섬 구경 (글은 읽기 전용) | v1 |

### 🏛️ 활성도 & 대항전
| 기능 | 설명 | 단계 |
|---|---|---|
| 랜드마크 성장 | 활성도에 따라 공사 중 → 완공 → 불꽃놀이 ([09 문서](09-island-and-avatar.md)) | MVP |
| 개인 기여도 | "내가 이번 주 랜드마크에 벽돌을 몇 개 쌓았는지" | MVP |
| 학과 대항 | 학교 안에서 학과(동물)끼리 주간 기여도 경쟁 | MVP |
| 리그 순위표 | 규모별 리그, 시즌 순위 ([04 문서](04-competition.md)) | v1 |
| 대항 이벤트 | 축제 기간 미션, 라이벌전 | v2 |

### 🎁 보상 & 수집
| 기능 | 설명 | 단계 |
|---|---|---|
| 일일 출석 | 출석하면 벽돌 1개 + 코인 | MVP |
| 일일 미션 | 매일 3개, 벽돌·코인 보상 ([11 문서](11-core-loop.md)) | MVP |
| 코인 & 상점 | 활동으로 코인 획득, 아바타 옷, 가구 구매 | v1 |
| 시즌 보상 | 리그 상위 학교 전원에게 한정 아이템 | v1 |
| 배지/도감 | 활동 업적 수집 | v2 |
