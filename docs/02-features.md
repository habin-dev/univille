# 02. 핵심 기능

## 1. 화면 구조

```
[월드맵]  바다 위에 전국 학교 섬들이 떠 있는 지도 (리그 순위, 섬 크기, 랜드마크 단계 표시)
   │
   ▼
[우리 학교 섬]  아이소메트릭 2D 섬, 중심에 학교 대표 건물 랜드마크
   ├─ 🏛️ 광장        → 자유게시판
   ├─ 📖 도서관      → 정보게시판 / 강의평
   ├─ 🛒 장터        → 중고거래 / 책 거래
   ├─ ☕ 카페        → 연애·고민 상담 (익명)
   ├─ 🎪 동아리 거리 → 동아리·행사 홍보
   ├─ 🏠 내 집       → 내 방 꾸미기, 내가 쓴 글
   ├─ 🏖️ 선착장     → 다른 학교 섬 방문, 전국 광장
   └─ 🏛️ 랜드마크   → 활성도, 이번 시즌 기여 순위, 학부 대항 순위
   │
   ▼
[게시판 화면]  일반적인 리스트/글 상세 화면 (빠르고 익숙하게)
```

- 섬은 **입구이자 분위기**이고, 실제 글 읽기, 쓰기는 **익숙한 리스트 UI**로 한다.
- 상단에 **"리스트 모드" 토글**: 섬을 건너뛰고 바로 게시판 목록으로 진입

## 3. MVP 범위 (첫 출시)

**목표: "우리 학교 섬에 들어와서 글 쓰고, 랜드마크가 지어지는 걸 본다"를 경험하게 하기**

**파일럿: 성결대학교 단일 학교**

1. 학교 이메일 인증 회원가입 + 학부 선택
2. 성결대학교 섬 화면 (정적인 2D 섬 + 건물 4개 + 랜드마크)
3. 기본 아바타 (학부별 동물 + 성결대 색상, 무늬/소품 몇 종)
4. 게시판: 자유, 정보, 장터, 홍보 (익명 글, 댓글, 공감, 신고)
5. 활성도 점수 계산 + 랜드마크 성장 단계 표시
6. 출석 체크
7. 학부 대항 순위표 (단일 학교이므로 학교 대항 대신)
8. 관리자 페이지 (신고 처리, 학교 등록)

**MVP에서 제외**: 실시간 아바타 이동 동기화, 채팅, 상점, 시간표, 강의평, 네이티브 앱 스토어 출시
