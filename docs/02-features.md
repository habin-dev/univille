# 02. 핵심 기능

## 1. 화면 구조

```
[월드맵]  전국 학교 마을들이 떠 있는 지도 (리그 순위, 나무 크기 표시)
   │
   ▼
[우리 학교 마을]  아이소메트릭 2D 마을, 중앙에 학교 나무
   ├─ 🏛️ 광장        → 자유게시판
   ├─ 📖 도서관      → 정보게시판 / 강의평
   ├─ 🛒 장터        → 중고거래 / 책 거래
   ├─ ☕ 카페        → 연애·고민 상담 (익명)
   ├─ 🎪 동아리 거리 → 동아리·행사 홍보
   ├─ 🏠 내 집       → 내 방 꾸미기, 내가 쓴 글
   └─ 🌳 학교 나무   → 활성도, 이번 시즌 기여 순위
   │
   ▼
[게시판 화면]  일반적인 리스트/글 상세 화면 (빠르고 익숙하게)
```

- 마을은 **입구이자 분위기**이고, 실제 글 읽기, 쓰기는 **익숙한 리스트 UI**로 한다.
- 상단에 **"리스트 모드" 토글**: 마을을 건너뛰고 바로 게시판 목록으로 진입

## 2. 기능 목록

### 🏘️ 마을 & 아바타
| 기능 | 설명 | 단계 |
|---|---|---|
| 학교별 마을 | 학교 인증 시 해당 학교 마을에 입주 | MVP |
| 아바타 | 동물 캐릭터 선택 + 옷, 소품 커스터마이징 | MVP (기본형) |
| 마을 돌아다니기 | 탭/클릭으로 이동, 건물 터치 시 게시판 진입 | MVP |
| 실시간 접속자 표시 | 지금 마을에 있는 다른 학생 아바타가 보임 | v1 |
| 말풍선 반응 | 아바타끼리 이모지 반응 (텍스트 채팅은 신고 이슈로 나중에) | v1 |
| 내 집 꾸미기 | 활동 보상으로 받은 가구로 방 꾸미기, 다른 사람 방 구경 | v1 |
| 마을 날씨, 계절 | 실제 날씨, 학사일정(시험기간, 축제) 반영 | v2 |

## 3. MVP 범위 (첫 출시)

**목표: "우리 학교 마을에 들어와서 글 쓰고, 나무가 자라는 걸 본다"를 경험하게 하기**

1. 학교 이메일 인증 회원가입
2. 학교 마을 화면 (정적인 2D 맵 + 건물 4개 + 학교 나무)
3. 기본 아바타 (동물 4~6종 선택)
4. 게시판: 자유, 정보, 장터, 홍보 (익명 글, 댓글, 공감, 신고)
5. 활성도 점수 계산 + 학교 나무 성장 단계 표시
6. 출석 체크
7. 전체 학교 순위표 (간단 버전)
8. 관리자 페이지 (신고 처리, 학교 등록)

**MVP에서 제외**: 실시간 아바타 이동 동기화, 채팅, 상점, 시간표, 강의평, 네이티브 앱 스토어 출시
