# 08. 성장 전략

> 커뮤니티는 **학교 하나에서 밀도가 생겨야** 살아난다. 전국에 얇게 뿌리지 않고, 학교 단위로 하나씩 산을 연다.

## 1. 콜드 스타트

글이 없으면 아무도 안 오고, 사람이 없으면 아무도 안 쓴다. 이미 쓰는 앱이 있으므로 처음부터 "갈아타기"를 요구하지 않는다. **"이것만은 여기가 더 편하다"**를 하나씩 만든다.

| 먼저 이기는 곳 | 이유 |
|---|---|
| **시간표 + 오늘 수업 카드** | 개학 첫 주에 모두가 필요함 |
| **강의평** | 강의평이 쌓이면 수강신청 때 반드시 들어옴 |
| **지금 캠퍼스** | 다른 앱에 없는 실시간 정보 |

## 2. 단계별

### Phase 1. 성결대 파일럿
- **오픈 시점: 학기 시작 2~3주 전** (수강신청·시간표 시즌)
- **강의평 씨앗 모으기**: 오픈 전 사전예약자에게 "들었던 과목 강의평 3개 쓰면 한정 장비" → 오픈 첫날부터 강의평이 있음
- **학과 동물 공개 이벤트**: "우리 학과는 어떤 동물?" 카드로 인스타·학과 단톡 공유
- **사전예약 = 첫 기여**: 사전예약자 수만큼 오픈 첫날 산길 진행도가 차 있음
- **셰르파단 모집**: 학과마다 1명 이상, 강의 데이터 정리와 질문 답변 담당
- 학생회·동아리 제휴: 홍보와 동아리 거리 무료 제공

### Phase 2. 학교 대항으로 확산
- **"우리 학교 산은 아직 안개 속"** 화면: 다른 학교 학생이 일정 수 이상 신청하면 그 학교 산을 연다 (대기 기간에 부지 윤곽·랜드마크 제작)
- 가까운 학교, 라이벌 학교를 묶어서 동시 오픈 → 바로 학교 대항
- 전망대가 열리면 다른 학교 산이 보임 → "저 학교는 벌써 정상이네" 자극

### Phase 3. 필수 앱으로 정착
- 스터디·팀플 매칭, 같이 밥·택시, 분실물 → 네트워크 효과
- 학사 일정 전체 연동, 졸업 요건 체크 같은 실용 기능 확대

## 3. 바이럴 장치

| 장치 | 설명 |
|---|---|
| 📸 **산 스냅샷** | 우리 학교 산, 내 캐릭터, 진행도를 인스타 스토리용 이미지로 |
| 🌫️ **안개 걷힘 카드** | "성결산 중턱 개방! 등반대원 412명" 공유 카드 |
| 🐾 **학과 동물 카드** | "나는 컴퓨터AI공학과 너구리" |
| 💌 **초대** | 같은 학교 친구 초대 → 둘 다 등반대원으로 기록 (참여 인원 조건에 직접 도움) |

## 4. 핵심 지표

| 지표 | 의미 |
|---|---|
| 학교별 가입률 | 학교 안 침투율 |
| 시간표 등록률 | 1층(실용)이 자리 잡았나 |
| 강의평 수 / 과목 커버리지 | 수강신청 시즌에 돌아올 이유 |
| D1 / D7 / D30 리텐션 | 습관이 됐나 |
| 기여한 적 있는 학생 비율 | 참여 문화 |
| "도움이 된 기여" 비율 | 기여가 품질로 이어지나 |
| 안개 해금 속도 | 시즌 설계가 맞나 |
