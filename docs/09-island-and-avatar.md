# 09. 섬 & 캐릭터 디자인

## 1. 학교 섬

학교마다 **섬 하나**가 있고, 전국의 섬들이 바다 위에 떠 있는 **월드맵**을 이룬다.

```
            🌊  🌊  🌊  🌊  🌊
        🌊   ┌──────────────┐   🌊
      🌊    │ 🛒장터  ☕카페   │    🌊
     🌊     │                 │     🌊
     🌊     │   🏛️ 랜드마크    │     🌊   ← 섬 중심: 학교 대표 건물
     🌊     │  (학교 대표 건물) │     🌊
      🌊    │ 📖도서관 🎪동아리 │    🌊
        🌊   │   🏖️ 선착장      │   🌊    ← 다른 학교 섬으로 가는 배
            └──────────────┘
            🌊  🌊  🌊  🌊  🌊
```

| 요소 | 설명 |
|---|---|
| 🏛️ **랜드마크** (섬 중심) | 학교의 대표 건물을 귀엽게 디포르메한 건물. 섬의 정체성이자 **활성도 상징물** |
| 주변 건물 | 광장(자유), 도서관(정보), 장터(거래), 카페(고민), 동아리 거리(홍보) |
| 🏖️ 선착장 | 다른 학교 섬 방문, 전국 광장으로 이동 |
| 🏠 집 구역 | 학생들의 집이 모여 있는 구역 |
| 섬 색감 | 학교 대표 색상이 지붕, 깃발, 꽃 색 등에 반영됨 |

### 섬 자체도 자란다
- 시즌 활성도가 높을수록 **섬의 땅이 넓어지고** 새로운 구역(해변, 숲, 언덕)이 열린다.
- 월드맵에서 큰 섬 = 활발한 학교 → 한눈에 비교 가능

## 2. 상징물: 🏛️ 랜드마크 (학교 대표 건물)

이전 기획의 "학교 나무"를 대신해 **섬 중심의 랜드마크가 활성도를 나타낸다.** 학교마다 모양이 달라서 정체성이 훨씬 강하다.

### (1) 성장 단계: 시즌 누적 활성도
| 단계 | 모습 |
|---|---|
| 1 | 🏗️ 공사 중 (비계와 크레인) |
| 2 | 🧱 외관 완성 |
| 3 | 💡 창문에 불이 켜짐 |
| 4 | 🚩 학교 색 깃발과 장식이 걸림 |
| 5 | 🌸 주변에 꽃과 분수가 생김 |
| 6 | 🎆 저녁마다 불꽃놀이 (학교 전원 보상 지급) |
| 7 | ✨ 황금 랜드마크 (리그 최상위권만) |

### (2) 컨디션: 최근 24시간 활기
| 상태 | 모습 |
|---|---|
| 북적임 | 랜드마크 주변에 NPC 학생들이 많고 음악이 흐름 |
| 보통 | 기본 |
| 한산함 | 불이 몇 개 꺼지고 "학생들이 보고 싶어요" 말풍선 |

### 개인의 기여: "벽돌 쌓기"
- 유효 활동(출석, 글, 댓글, 받은 공감)이 **벽돌**로 환산되어 랜드마크에 쌓임
- 랜드마크를 터치하면 "이번 주 벽돌 쌓기 TOP 10", "내가 쌓은 벽돌" 확인
- 점수 공식은 [03 문서](03-activity-score.md)를 그대로 사용

### 제작 방식
- 학교마다 랜드마크 일러스트를 **3~4개 변형(단계별)**으로 제작해야 함 → 학교 수만큼 아트 비용 발생
- 초기 대응: **공통 베이스 건물 + 학교별 지붕/외벽/상징 장식 교체**로 반자동 제작, 파일럿 학교만 완전 커스텀
- 학교 오픈 요청이 일정 수 이상 모이면 랜드마크 제작에 착수 (오픈 대기 기간 = 제작 기간)

## 3. 동물 아바타

### 규칙
- **학부(단과대)마다 동물이 지정**된다. 같은 학부 학생은 같은 동물.
- **학교마다 색상이 다르다.** 학교 대표 색이 털 색 포인트, 스카프, 옷에 반영된다.
- 그 안에서 개인은 **털 무늬, 표정, 옷, 소품**으로 꾸민다.

→ 섬에서 다른 아바타를 보면 **"아, 공대 비버구나"**, 다른 학교 섬에 가면 **"색이 다르네, 다른 학교 사람이구나"**를 바로 알 수 있다.

### 계열별 동물 (전국 공통 기준안)

학교마다 학부 이름과 구성이 다르므로, **전국 공통 "계열"에 동물을 지정**하고 각 학교의 학부를 계열에 매핑한다. 같은 동물끼리 학교를 넘어 연대하는 재미도 생긴다 (예: "전국 비버 모임").

| 계열 | 동물 | 이미지 |
|---|---|---|
| 공학 | 🦫 비버 | 무언가를 만드는 장인 |
| 자연과학 | 🦉 부엉이 | 관찰과 탐구 |
| 인문 | 🐑 양 | 차분한 사색 |
| 신학/종교 | 🕊️ 비둘기 | 평화 |
| 사회과학 | 🦊 여우 | 영리함, 사회성 |
| 경영/경제 | 🐿️ 다람쥐 | 차곡차곡 모으기 |
| 사범/교육 | 🐧 펭귄 | 무리를 이끄는 선생님 |
| 예술/디자인 | 🐱 고양이 | 자유로운 감성 |
| 체육 | 🐆 치타 | 스피드 |
| 의약/간호/보건 | 🐨 코알라 | 포근한 돌봄 |
| IT/컴퓨터 | 🦝 너구리 | 밤샘 코딩 |
| 자유전공/기타 | 🐰 토끼 | 어디든 갈 수 있음 |

- 동물 목록은 확정 전 **설문으로 투표**해서 정하면 그 자체가 홍보 이벤트가 됨
- 복수전공, 전과 시 동물 변경 1회 허용

### 학교 색상
- `schools.primary_color`, `secondary_color`로 관리
- 아바타의 스카프, 모자, 털 포인트 + 섬의 지붕, 깃발에 적용
- 비슷한 색의 학교끼리는 **채도, 명도를 조정**하거나 보조 색으로 구분

### 학부 대항 (학교 안의 경쟁)
- 학교 대항전과 별개로 **학교 안에서 학부끼리** 이번 주 벽돌 기여도를 겨룸
- 랜드마크 주변에 1위 학부 동물의 동상이 세워짐
- 학교 대항전에 참여할 동기를 학부 단위로도 부여

## 4. 파일럿: 성결대학교

성결대학교의 색상, 학과 목록, 학과별 동물 매핑, 건물 배치, 랜드마크 후보는 **[10. 파일럿: 성결대학교](10-pilot-sungkyul.md)**에 정리했다.

> 학교 상징(로고, 교표, 공식 마스코트 '스쿠아')은 학교의 권리이므로 **사용하지 않거나 학교 허가를 받는다.** 건물 외관을 참고한 오리지널 일러스트와 색상 톤만 사용하는 것을 기본으로 한다.
