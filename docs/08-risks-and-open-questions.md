# 08. 리스크 & 결정할 것

## 1. 리스크

| 리스크 | 영향 | 대응 |
|---|---|---|
| **기존 커뮤니티의 네트워크 효과** | 사람들이 굳이 옮기지 않음 | "대체"가 아니라 "재밌는 추가 공간"으로 시작. 학교 단위 밀도 집중 |
| **게임 요소가 귀찮음** | 정보만 원하는 유저가 이탈 | 리스트 모드 상시 제공, 마을은 선택 |
| **특정 게임과 비슷해 보이는 디자인** | 저작권, 상표 분쟁 | 캐릭터, 아트, UI, 이름 모두 오리지널로 제작. 특정 게임의 캐릭터나 에셋, 명칭 사용 금지 |
| **경쟁 과열 & 비방** | 커뮤니티 분위기 악화 | 비방 점수 차감, 교류전 등 협력 이벤트 병행 |
| **익명 커뮤니티 모더레이션** | 법적 책임, 운영 부담 | 신고 자동 블라인드, AI 필터, 학교별 이장님 제도 |
| **개인정보 (학교 이메일)** | 유출 시 큰 타격 | 이메일은 인증 후 해시 저장 검토, 최소 수집 |
| **점수 어뷰징** | 대항전 신뢰도 하락 | [03 문서](03-activity-score.md)의 방지책 + 이상 학교 점수 검토 |
| **아트 비용** | 귀여움이 핵심인데 비용이 큼 | MVP는 소수 에셋으로 시작, 시즌 아이템부터 점진 추가 |
| **1인 개발 운영 부담** | 모더레이션, CS 과부하 | 파일럿 학교 수 제한, 운영 자동화 우선 |

## 2. 아직 결정할 것

- [ ] **공간 컨셉**: 섬 / 마을 / 숲 / 캠퍼스 중 무엇으로 할까?
- [ ] **캐릭터**: 동물 아바타? 사람 아바타? 학교별 마스코트?
- [ ] **상징물**: 학교 나무로 확정할까?
- [ ] **익명성 수준**: 완전 익명 / 닉네임 / 선택형
- [ ] **활성도 공식 가중치**: 파일럿 데이터로 보정 필요
- [ ] **파일럿 학교**: 어디서 시작할까?
- [ ] **서비스 이름**: 유니빌 외 후보
- [ ] **아트 제작 방식**: 직접 / 외주 / 에셋 구매
