# 01. 서비스 개요

## 1. 문제 정의

| 지금 대학 커뮤니티의 문제 | 결과 |
|---|---|
| 게시판 목록만 있는 UI라 **볼거리, 재미 요소가 없음** | 필요할 때(시간표, 강의평)만 들어오고 금방 나감 |
| 글을 써도 **보상이나 성장의 감각이 없음** | 소수만 글을 쓰고 대다수는 눈팅만 함 |
| 학교가 **각자 닫혀 있음** | 다른 학교와 교류하거나 비교할 계기가 없음 |
| 분위기가 날카롭고 **익명 비방이 잦음** | 처음 온 사람이 머물기 어려움 |

## 2. 해결 방향

1. **공간화**: 게시판을 "마을 안의 장소"로 바꿔 둘러보는 재미를 줌
2. **가시화**: 우리 학교 커뮤니티가 얼마나 살아 있는지 **학교 나무**로 보여줌
3. **경쟁**: 학교끼리 시즌제 대항전을 하며 "우리 학교를 위해" 참여할 이유를 줌
4. **귀여움**: 둥글고 따뜻한 아트 스타일로 분위기 자체를 부드럽게 만듦

## 3. 타깃 사용자

| 페르소나 | 특징 | 유니빌에서 원하는 것 |
|---|---|---|
| 🐣 **새내기 지민 (20)** | 학교에 아는 사람이 없음, 귀여운 것 좋아함 | 부담 없이 학교 사람들과 어울리기, 마을 꾸미기 |
| 📚 **3학년 도윤 (23)** | 정보성 글(강의, 취업) 위주로 이용 | 빠른 정보 검색, 신뢰할 수 있는 글 |
| 🔥 **과대/동아리장 서연 (22)** | 학교 행사, 홍보에 적극적 | 홍보 공간, 학교 대항전에서 우리 학교 1등 만들기 |

## 4. 차별점

| | 기존 대학 커뮤니티 | 유니빌 |
|---|---|---|
| UI | 텍스트 게시판 목록 | 2D 마을 + 게시판 |
| 참여 동기 | 정보 필요할 때만 | 정보 + 꾸미기 + 학교 대항전 |
| 학교 간 관계 | 단절 | 리그, 교류 이벤트, 방문 |
| 분위기 | 건조, 날카로움 | 귀엽고 따뜻함 |
| 기본 기능 | 시간표, 강의평, 게시판 | (단계적으로) 동일하게 제공 |

> ⚠️ 마을과 게임 요소는 **"있으면 재미있는 것"**이어야 하고, 게시판을 쓰기 불편하게 만들면 안 된다. 언제든 **"리스트 모드"**로 바로 글을 볼 수 있어야 한다.

## 5. 목표

- **최종 목표**: 국내 대학생 커뮤니티 1위 서비스 수준의 대학생 이용자 확보
- **중간 목표 (KPI)**

| 단계 | 기간 | 목표 |
|---|---|---|
| 파일럿 | 출시 후 3개월 | 1~3개 학교, 학교별 재학생의 10% 가입, 가입자 중 DAU 30% |
| 확장 | 6~12개월 | 30개 학교, 누적 가입 10만 명 |
| 전국 | 1~2년 | 전국 4년제 대부분, 누적 가입 100만 명 이상 |
