# 04. 기여도 설계

## 1. 원칙

1. **기여 = 다른 학생에게 도움이 된 행동.** 많이 한 것보다 **도움이 된 것**이 더 크다.
2. **다른 사람이 인정해야 크게 오른다.** 채택, "도움 됨", 공감처럼 다른 학생의 반응이 붙은 행동에 높은 점수를 준다.
3. **하루 상한이 있다.** 도배로 오를 수 없다.
4. **규모를 보정한다.** 큰 학교가 무조건 앞서지 않는다.
5. **넓은 참여가 필요하다.** 소수 헤비 유저만으로는 안개가 걷히지 않는다.

## 2. 행동별 기여 (초안)

| 행동 | 기여 | 조건 / 상한 |
|---|---|---|
| **강의평 작성** | 30 | 수강한 과목(시간표 등록)만, 최소 글자 수, 과목당 1회 |
| **질문 답변 채택** | 25 | 질문자가 채택, 자기 질문 자기 답변 제외 |
| **지금 캠퍼스 제보 → "도움 됨"** | 받은 "도움 됨" 1개당 2 | 제보 1건당 최대 10 |
| **학식 사진·평점** | 5 | 하루 1회 |
| **반응 많은 글** (서로 다른 10명 이상 공감) | 10 | 글 1개당 1회 |
| **장터 거래 완료 + 상대방 후기** | 10 | 같은 상대와 주 1회 |
| 글 작성 | 2 | 하루 5개까지 |
| 댓글 | 1 | 하루 10개까지 |
| 출석 | 2 | 하루 1회 |
| 오늘의 등반 3개 완료 | 10 | 하루 1회 |

- **1인 하루 기여 상한: 80** (강의평 몰아 쓰기 기간에는 강의평만 별도 상한)
- 삭제·블라인드된 글의 기여는 회수한다. 제재받으면 해당 기간 기여는 학교·학과 점수에서 빠진다.

## 3. 기여가 쓰이는 세 곳

```
             개인 기여 (오늘 +12)
           ┌────────┼────────┐
           ▼        ▼        ▼
       학교 산    학과 등반대   내 등급
     (안개 해금)  (주간 경쟁)   (혜택, 장비)
```

| 어디에 | 무엇을 쓰나 | 사라지나 |
|---|---|---|
| **학교 산** | 학교 전체의 누적 기여 + 참여 인원 | 걷힌 안개는 영구. 시즌 등반량은 시즌마다 새로 계산 |
| **학과 등반대** | 이번 주 학과 기여 (학과 인원으로 보정) | 매주 새로 시작 |
| **내 등급** | 개인 누적 기여 | **줄어들지 않음** |

## 4. 안개 해금 조건

구역이 열리려면 **두 가지를 모두** 채워야 한다.

| 구역 | ① 1인당 누적 기여 (학교 전체 기여 ÷ 재학생 수) | ② 참여 인원 (기여한 적 있는 학생 ÷ 재학생 수) |
|---|---|---|
| 1. 산길 | 20 | 5% |
| 2. 중턱 | 60 | 10% |
| 3. 전망대 | 150 | 15% |
| 4. 정상 | 300 | 20% |

- **①은 규모 보정**: 재학생 수로 나누므로 작은 학교도 같은 조건이다.
- **②는 넓은 참여**: 몇 명이 혼자 열 수 없다. "같이 올라가자"는 이유가 된다.
- 숫자는 초안이다. 파일럿에서 **정상까지 약 1학기(3~4시즌)**가 걸리도록 보정한다.
- 홈 화면에는 두 조건 중 **더 부족한 쪽**을 보여준다: "산길까지 72%" / "등반대원이 30명 더 필요해요".

## 5. 시즌 등반량 (학교 대항용)

걷힌 안개는 영구라서, 먼저 시작한 학교가 항상 높이 있다. 그래서 학교끼리는 **누적 높이가 아니라 이번 시즌에 얼마나 올랐나**로 겨룬다.

```
시즌 등반량 = 100 × ( 0.4 × 1인당 이번 시즌 기여 (백분위)
                   + 0.3 × 이번 시즌 참여 인원 비율 (백분위)
                   + 0.2 × 도움이 된 기여 비율 (강의평·채택·도움 됨)
                   + 0.1 × 재방문율 )
```

## 6. 어뷰징 방지

| 유형 | 대응 |
|---|---|
| 도배 | 행동별·하루 상한, 유사 문장 탐지 |
| 품앗이 (채택·공감·도움 됨 주고받기) | 같은 사용자 쌍 반복 시 점수 감소, 관계 그래프 이상 탐지 |
| 가짜 강의평 | 시간표에 등록한 과목만, 학기당 1회, 신고 시 회수 |
| 다중 계정 | 학교 메일 1개당 1계정, 기기 정보 |
| 매크로 | 레이트 리밋, 의심 시 캡차 |
| 제보 남발 | "틀린 정보" 표시가 많으면 제보 기여 회수, 제보 권한 일시 정지 |
