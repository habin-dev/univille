# 강의시간표 변환기 (성결대학교)

학사 공지 **"OO학년도 O학기 강의시간표 안내"**에 첨부된 시간표 PDF를 앱의 과목 데이터로 바꾼다.
시간표 카드("다음 수업 14:40 성결관 407"), 강의평 과목 목록, 강의동 벽돌 배정의 원본이 된다.

## 준비

```bash
pip install -r requirements.txt
```

## 변환

1. 학교 홈페이지 학사 공지에서 이번 학기 "강의시간표 안내"를 열고, `OO학기 시간표(날짜).pdf`를 받는다.
2. 실행:

```bash
python timetable.py 시간표.pdf --term 2026-2 --out data/2026-2
```

| 출력 | 내용 |
|---|---|
| `sections.json` | 분반 목록. 앱 과목 DB에 넣는 원본 |
| `sections.csv` | 같은 내용의 표 (엑셀 확인용) |
| `report.md` | 건수, 건물·요일·학과별 통계, 해석하지 못한 값 목록 |

> PDF와 변환 결과(`data/`)는 저장소에 올리지 않는다 (`.gitignore`). 학교 자료 이용 조건을 확인하기 전까지는 로컬에서만 쓴다.

## 오늘 수업 카드 확인

```bash
python today.py data/2026-2/sections.json --dept 컴퓨터공학과 --year 2 --at "2026-11-24 13:50"
```

학과·학년의 전공 과목으로 겹치지 않는 예시 시간표를 만들고, 주간표와 "다음 수업" 카드를 출력한다.

## 해석 규칙

| 항목 | 규칙 |
|---|---|
| 수업시간 | `월1-3` → 월요일 1~3교시 09:00~11:40. 교시표는 안내문 기준 (1~15교시, 10교시부터 Ⅱ부) |
| 강의실 | `중`중생관 `성`성결관 `기`기념관 `영`영암관 `재`재림관 `학술`학술정보관 (안내문 약자표) |
| 강의실 (추정) | `학`은 안내문에 없음. 체육관·무도실이 있는 **학생회관**으로 추정 |
| 층 | `중201` → 2층, `성B101` → 지하(-1) |
| 셀 줄바꿈 | 좁은 칸에서 잘린 단어라 붙여서 합침 |
| 학과 | 각 페이지 표 위의 제목. `(2부)`는 야간으로 표시 |

## 남은 과제

- 페이지 제목에 학과 대신 **전공 이름**(`성악 전공`, `바이오화장품공학 전공` 등)이 나오는 경우가 있다. 앱의 학과 목록과 연결하는 매핑표가 필요하다.
- 학과 이름이 개편 전 이름이다 (`컴퓨터공학과` 등). 개편 후 이름과 함께 매핑한다 ([14 문서](../../docs/14-sungkyul-data.md)).
- 교양(파이데이아학부) 과목은 모든 학과 학생이 듣는다. 시간표 검색에서 학과와 상관없이 보이게 한다.
- 수강신청 기간에는 PDF가 자주 갱신된다 (파일명 뒤 날짜). 갱신본을 다시 변환하고 바뀐 분반만 반영하는 기능이 필요하다.
